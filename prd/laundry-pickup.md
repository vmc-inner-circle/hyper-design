# 동네 세탁 수거·배송 앱 — 기획 브리프 + MVP 기능명세서

> 작성: 서비스기획 PM / 최종 수정: 2026-10-13 / 상태: 에이전시 전달용 초안 v0.8
> "무엇을" 만들지 정리한 문서입니다. "어떻게 보일지"는 에이전시 제안을 받고 싶습니다. 미확정 사항은 7장에 모았고, 본문에도 (논의 중) 표시가 있습니다.

---

## 1. 서비스 개요

집 앞에 세탁물을 내놓으면 동네 제휴 세탁소가 수거해 가서 세탁한 뒤 다시 문 앞에 가져다주는 **이용자용 모바일 앱**입니다.

동네 세탁소는 대부분 방문 접수만 받습니다. 맞벌이·1인 가구는 영업시간에 세탁소에 들르기 어렵고, 세탁소는 "언제 찾으러 오세요?" 전화와 찾아가지 않은 옷 보관에 시간을 씁니다.

| 구분 | 설명 | MVP 범위 |
|---|---|---|
| 이용자 | 수거 신청·결제·진행 확인·배송 받기 | **이번 외주 범위 (모바일 앱)** |
| 제휴 세탁소 | 접수 확인·검수·가격 확정·완료 처리 | 범위 외 — **별도 웹 어드민** (내부 개발 중) |
| 수거·배송 기사 | 수거·배송 동선, 사진 인증 | 범위 외 — 기사용 앱 (2차) |

**이번 외주는 이용자 앱만 해당합니다.** iOS/Android, 세로 화면 기준입니다.

---

## 2. 우리가 해결하고 싶은 문제

1. **세탁소 영업시간에 맞출 수 없다** — 평일 9~19시 영업, 이용자는 출근 전·퇴근 후에만 시간이 남. 맡기고 찾는 데 왕복 두 번.
2. **가격을 맡기기 전에 모른다** — "와이셔츠 얼마예요?", "얼룩 빼면 추가 있어요?"를 매번 물어봄. 검수 후 가격이 바뀌면 분쟁.
3. **진행 상황이 안 보인다** — 언제 끝나는지 몰라서 전화. 급한 옷(면접·결혼식)은 특히 불안.
4. **손상·분실 책임이 애매하다** — 맡길 때 상태 기록이 없어서 "원래 있던 얼룩"인지 다툼.
5. (부가) **정기 세탁** — 매주 같은 요일에 와이셔츠 5장을 맡기는 이용자가 많음. 매번 신청이 번거롭다.

---

## 3. 타깃 사용자와 사용 맥락

**A. 이도윤 (34세, 직장인, 1인 가구)** — 오피스텔 거주. 주 1회 와이셔츠 5장, 계절마다 코트·패딩.
- 일요일 밤, 다음 주 셔츠를 문 앞에 내놓고 앱으로 수거 신청
- 수요일 점심, "목요일 저녁 배송 가능한지" 확인
- 배송 완료 알림을 받고 퇴근 후 문 앞에서 찾음

**B. 한지민 (41세, 맞벌이, 아이 둘)** — 아파트. 이불·아이 옷·운동화 등 품목이 다양하고 양이 많음.
- 품목별 가격을 미리 보고 예산 안에서 고르고 싶음
- 아이 교복 얼룩 — 추가 요금 여부를 맡기기 전에 알고 싶음
- 검수 결과 "얼룩 제거 불가"라면 그 옷만 빼고 진행하고 싶음

## 4. MVP 기능 명세

### 4.1 가입·주소
- F-01 휴대폰 번호 인증 가입. 소셜 로그인은 (논의 중)
- F-02 주소 등록: 도로명 + 상세 주소 + 출입 방법(공동현관 비밀번호, 경비실 맡김 등). 주소 여러 개 저장
- F-03 서비스 지역 밖이면 "오픈 알림 받기"로 연락처만 받는다

### 4.2 수거 신청
- F-10 품목 선택: 카테고리(셔츠·바지·니트·코트·이불·운동화·기타)별 기본 가격 표시
- F-11 수량은 대략 입력 — 실제 수량·가격은 세탁소 검수 후 확정된다는 안내 필수
- F-12 요청 사항: 얼룩 위치·종류, 다림질 여부, 향 없는 세제 등 (자유 입력 + 자주 쓰는 칩)
- F-13 수거 시간대: 오늘 밤 22~24시 / 내일 아침 6~8시 등 **2시간 단위**, 마감된 시간대는 비활성
- F-14 배송 희망: 일반(3일) / 빠른(익일, +3,000원). 품목에 따라 빠른 배송 불가(이불·운동화)
- F-15 신청 전 요약: 품목·예상 금액·수거/배송 시간·주소·출입 방법 한 화면 확인

### 4.3 결제
- F-20 카드 등록 후 **검수 확정 시 자동 결제**. 신청 시점에는 결제하지 않음
- F-21 검수 금액이 예상 금액보다 20% 이상 많으면 자동 결제 전에 이용자 승인 필요
- F-22 쿠폰·첫 이용 할인 (논의 중)

### 4.4 진행 확인
- F-30 단계: 신청 → 수거 완료 → 검수 → 세탁 중 → 배송 중 → 배송 완료
- F-31 수거 시 기사가 찍은 사진, 검수 시 세탁소가 찍은 품목별 사진을 이용자가 볼 수 있음
- F-32 검수 결과 품목별 조정: "얼룩 제거 불가 — 진행 / 이 품목 빼고 돌려받기" 선택
- F-33 단계가 바뀔 때마다 푸시 알림. 배송 완료 시 문 앞 사진 포함

### 4.5 이용 내역·정기 세탁
- F-40 이용 내역: 주문별 품목·금액·사진·영수증
- F-41 지난 주문 그대로 다시 신청
- F-42 정기 세탁: 요일·시간대·기본 품목 설정, 그 주 건너뛰기 가능 (논의 중 — MVP 포함 여부)

### 4.6 문의·보상
- F-50 주문별 1:1 문의 (채팅형). 운영 시간 외에는 접수만
- F-51 손상·분실 신고: 배송 후 48시간 이내, 사진 첨부. 수거·검수 사진과 함께 심사

---

## 5. 정책

- 수거 시간대 시작 1시간 전까지 무료 취소. 이후 취소는 수거비 2,000원
- 문 앞에 세탁물이 없으면 "수거 실패" 처리, 수거비 2,000원 부과, 재신청 필요
- 최소 주문 금액 15,000원. 미만이면 수거비 3,000원 추가
- 검수 후 이용자 승인이 필요한 건(F-21)은 24시간 안에 응답이 없으면 **예상 금액 범위의 품목만** 진행
- 가죽·모피·명품은 MVP에서 접수 불가 — 품목 선택에서 안내

- 수선(기장 줄이기 등), 보관 서비스

## 7. 미확정 사항

1. 소셜 로그인 포함 여부 (F-01)
2. 쿠폰·첫 이용 할인 구조 (F-22)
3. 정기 세탁을 MVP에 넣을지 (F-42)
4. 빠른 배송 요금을 지역별로 다르게 할지
5. 앱 이름·브랜드 톤 — 에이전시 제안 희망. 깔끔하고 믿음 가는 인상이면 좋겠음
