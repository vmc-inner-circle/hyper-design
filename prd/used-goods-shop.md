# 검수 중고 가전·가구 판매 앱 — 기획 브리프 + MVP 기능명세서

> 작성: 서비스기획 PM / 최종 수정: 2026-10-14 / 상태: 에이전시 전달용 초안 v0.6
> "무엇을" 만들지 정리한 문서입니다. "어떻게 보일지"는 에이전시 제안을 받고 싶습니다. 미확정 사항은 7장에 모았고, 본문에도 (논의 중) 표시가 있습니다.

---

## 1. 서비스 개요

중고 가전·가구를 **매입해 직접 검수·세척한 뒤 판매하는 업체**의 **고객용 모바일 앱**입니다. 개인 간 거래가 아니라 업체가 판매자이며, 모든 상품은 검수 등급과 보증 기간이 붙습니다. 첫 고객은 수도권 물류센터 1곳과 오프라인 전시장 2곳을 운영하는 중고 전문 업체이며, 지금은 스마트스토어와 전화 주문으로 팔고 있습니다.

지금은 상품 상태를 사진 몇 장과 "상태 좋음" 같은 말로만 전해서 "생각보다 낡았다" 반품이 많고, 배송·설치 일정은 전화로 잡습니다. 고객은 같은 모델의 새 제품 가격과 비교하기 어렵고, 업체는 "이 냉장고 아직 있나요?" 문의에 시간을 씁니다.

| 구분 | 설명 | MVP 범위 |
|---|---|---|
| 구매 고객 | 상품 탐색·비교, 검수 리포트 확인, 구매·결제, 배송·설치 일정, 반품·보증 | **이번 외주 범위 (모바일 앱)** |
| 판매(매입) 고객 | 내 물건 매입 견적 신청 | 일부 범위 — 견적 신청까지만 (4.6) |
| 업체 직원 | 검수 입력, 재고·주문·배송 관리 | 범위 외 — **별도 웹 어드민** (내부 개발 중) |

**이번 외주는 고객 앱만 해당합니다.** iOS/Android, 세로 화면 기준입니다.

## 2. 우리가 해결하고 싶은 문제

1. **상품 상태를 믿기 어렵다** — 사진과 짧은 문구뿐이라 흠집·사용 기간·작동 여부를 알 수 없음. 반품 사유 1위가 "설명과 상태가 다름".
2. **새 제품보다 얼마나 싼지 모른다** — 같은 모델 신품가와 비교할 수 없어 결정을 미루고 이탈.
3. **배송·설치 일정이 전화로만 잡힌다** — 대형 가전·가구는 기사 방문이 필요한데, 날짜 조율에 통화가 2~3번 오감.
4. **재고 문의가 많다** — 한 점뿐인 상품이라 이미 팔렸는지 묻는 전화·채팅이 하루 수십 건.
5. (부가) **보증·반품 절차를 모른다** — 고장 나면 어디에 연락해야 하는지, 보증 기간이 남았는지 확인할 곳이 없음.

## 3. 타깃 사용자와 사용 맥락

**A. 박서윤 (31세, 신혼, 첫 집 꾸미기)** — 예산이 빠듯해 냉장고·세탁기·식탁을 중고로 장만하려 함.
- 퇴근길 지하철에서 "양문형 냉장고"를 검색하고 A등급만 골라 봄
- 검수 리포트의 흠집 사진과 신품가 대비 할인율을 보고 찜
- 이사 날짜에 맞춰 배송·설치 날짜를 고르고 결제
- 설치 후 한 달 뒤 소음이 생겨 보증 수리를 앱에서 신청

**B. 이준혁 (52세, 자영업, 가게 정리 중)** — 폐업하는 카페의 제빙기·쇼케이스를 팔고, 집에 둘 안마의자는 사고 싶음.
- 매입 견적을 사진 몇 장으로 먼저 받아 보고 싶음
- 안마의자는 전시장에 가서 직접 앉아 보고 싶어 재고 위치를 확인

## 4. MVP 기능 명세

### 4.1 가입·로그인
- F-01 휴대폰 번호 인증 가입, 카카오 로그인. 둘러보기는 로그인 없이 가능, 찜·구매부터 로그인
- F-02 배송지 등록: 주소, 엘리베이터 유무, 층수 — 대형 상품 배송비·설치 가능 여부 계산에 사용

### 4.2 탐색
- F-10 홈: 오늘 입고된 상품, 카테고리(냉장고·세탁기·TV·에어컨·소파·침대·식탁·주방가전 등 12개), 기획전
- F-11 검색: 모델명·브랜드·카테고리. 필터 — 검수 등급(S·A·B), 가격대, 제조 연도, 배송 가능 지역, 전시장 재고
- F-12 상품 목록: 사진, 상품명, 검수 등급, 판매가, **신품가 대비 할인율**, 보증 기간
- F-13 찜: 찜한 상품이 팔리거나 가격이 내리면 알림

### 4.3 상품 상세
- F-20 사진(정면·측면·흠집 확대), 판매가·신품가·할인율, 제조 연도, 사용 기간 추정
- F-21 **검수 리포트**: 항목별 결과(외관·작동·소음·냄새·부품), 흠집 위치를 표시한 사진, 검수자·검수일. 등급 기준(S: 거의 새것, A: 생활 흠집, B: 눈에 띄는 흠집·작동 정상)
- F-22 보증: 기본 3개월(S등급 6개월). 보증 범위와 제외 항목
- F-23 재고 위치: 물류센터 / 전시장(지점명). 전시장 재고면 "방문해서 보기" 예약 (논의 중)
- F-24 한 점뿐인 상품 — 다른 고객이 결제 진행 중이면 "결제 진행 중" 표시

### 4.4 구매
- F-30 장바구니: 여러 상품을 담되 배송은 상품별로 일정이 다를 수 있음
- F-31 배송·설치 날짜 선택: 지역별 가능 날짜 달력, 오전/오후. 대형 상품은 설치 기사 방문, 소형은 택배
- F-32 결제: 카드, 간편결제, 무통장. 배송비는 층수·엘리베이터·지역으로 계산해 결제 전에 표시
- F-33 주문 완료: 주문 번호, 배송 예정일, 기사 방문 시간대 안내
- F-34 주문 내역·배송 조회: 결제 완료 → 배송 준비 → 배송 중 → 설치 완료

### 4.5 반품·보증
- F-40 반품 신청: 수령 7일 안, 사유 선택(설명과 다름·작동 이상·단순 변심), 사진 첨부. 단순 변심은 왕복 배송비 고객 부담
- F-41 보증 수리 신청: 증상 선택·설명·사진, 방문 희망 날짜. 보증 기간이 끝났으면 유상 수리 견적 안내
- F-42 신청 진행 상황: 접수 → 확인 중 → 방문 예정 → 완료

### 4.6 매입 견적 (내 물건 팔기)
- F-50 견적 신청: 카테고리·브랜드·모델명(모르면 사진), 구입 연도, 상태, 사진 3장 이상, 수거 주소
- F-51 견적 결과: 예상 매입가 범위, 방문 수거 날짜 제안. 수락하면 수거 예약까지 (실제 정산은 방문 검수 후 확정)

## 5. 정책

- 모든 상품은 업체 검수를 거친 1점 상품. 결제 진행 중인 상품은 10분간 다른 고객이 결제할 수 없음
- 반품은 수령 후 7일 이내. 설명과 다르거나 작동 이상이면 업체 부담, 단순 변심은 왕복 배송비 고객 부담. 설치 후 단순 변심 반품은 불가
- 보증 기간: S등급 6개월, A·B등급 3개월. 고객 과실·소모품(필터·리모컨 배터리)은 제외
- 배송비: 소형 무료, 대형은 기본 3만 원 + 엘리베이터 없는 3층 이상은 층당 1만 원. 제주·도서 지역 배송 불가
- 매입 견적은 예상가이며, 방문 검수 결과에 따라 달라질 수 있음

## 6. 범위 밖

- 업체 직원용 화면 전부(검수 입력, 재고·주문 관리)
- 개인 간 거래, 경매
- 렌탈·구독
- 해외 배송

---

## 7. 미확정 사항

1. 전시장 방문 예약을 MVP에 넣을지 (F-23)
2. 무통장 입금 허용 여부 — 1점 상품이라 입금 대기 중 재고를 잡아 둘 시간 (F-32)
3. 매입 견적을 사진 자동 판별로 할지, 직원이 답할지 (F-50)
4. 앱 이름·브랜드 톤 — 에이전시 제안 희망. "중고"의 낡은 느낌 대신 믿을 수 있고 깔끔한 인상이면 좋겠음
