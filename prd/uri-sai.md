# 우리사이 — 둘이 쓰는 비공개 공유앨범 · 디자인 명세서

> 작성: 2026-10-06 / 원본: `greatSumini/uri-sai` docs/PRD.md(v1, 개발용)에서 화면에 드러나는 것만 옮겨 다시 씀
> 서버·저장소·데이터베이스 구조는 이 문서의 범위가 아닙니다. "무엇이 보이고, 어디서 막히는가"만 적습니다.
> iOS·Android, 세로 화면. 태블릿·웹은 범위 외.

## 1. 배경 — 둘 사이에만 있는 문제

연인 둘이 함께 찍은 사진은 두 사람의 폰에 반씩 흩어져 있다. 데이트가 끝나면 카톡으로 사진을 몇십 장씩 주고받지만, 화질이 깨지고 대화방에 묻히고, 몇 달 뒤 "그때 그 사진" 을 찾으려면 서로에게 물어봐야 한다. 클라우드 공유앨범은 계정·초대·용량 설정이 번거롭고, 남이 볼 수도 있다는 찜찜함이 남는다.

우리사이는 **딱 두 사람만** 쓰는 앨범이다. 그래서 일반 공유앨범과 다른 긴장이 있다.

1. **누구나 누구의 사진이든 지울 수 있고, 지워도 상대에게 알림이 가지 않는다.** 내가 못 나온 사진을 지우는 건 자연스럽지만, 상대가 아끼던 사진이었다면 서운할 수 있다. 그래서 지운 사진은 14일 동안 휴지통에 남고, 누가 지웠는지 보이고, 둘 다 되살릴 수 있다. 휴지통이 둘 사이의 유일한 "말 없는 대화" 다.
2. **"올렸는데 없어" 는 앱에 대한 신뢰보다 상대에 대한 서운함으로 번진다.** 업로드는 절대 조용히 실패하면 안 된다. 실패하면 눈에 보여야 하고, 다시 시도할 수 있어야 한다.
3. **상대가 뭘 올렸는지 매번 묻기는 애매하다.** 알림은 없다(일부러 뺐다). 대신 앱을 열면 상대가 그사이 올린 것이 자연스럽게 눈에 걸려야 한다.

## 2. 사용자

딱 두 명이고, **권한은 완전히 같다.** 누가 관리자도 아니고, 누가 보기만 하는 사람도 아니다.

**A. 수민 (31세, 개발자, Android)** — 이 앱을 만든 사람. 사진을 많이 찍지는 않지만 정리 욕심이 있다. 데이트 사진을 앨범으로 묶고, 가끔 에이전트(SimpleClaw)에게 "작년 바다 사진 찾아줘" 를 시킨다.
- 데이트 끝나고 집 가는 지하철에서, 오늘 찍은 사진 20~40장을 한 번에 올린다
- 주말에 앨범 정리: "제주 2025" 앨범에 사진을 모으고, 흔들린 사진을 지운다
- 에이전트가 대신 올린 사진이 잘 들어갔는지 확인한다

**B. 지윤 (29세, 디자이너, iPhone)** — 사진을 훨씬 많이 찍는다(음식·풍경·서로의 뒷모습). 앱 설치는 TestFlight 초대를 받아 처음 해 본다. 기술적인 말에 거부감이 있다.
- 자기 전에 침대에서, 수민이 오늘 올린 사진을 넘겨 본다
- 갤러리에서 사진을 고르다가 "공유 → 우리사이" 로 바로 올린다
- 기념일 전에 "작년 이맘때 우리" 를 찾아본다
- 자기가 아끼던 사진이 안 보이면 휴지통부터 확인한다

**공통**: 한 번 열면 1~5분. 대부분 "새로 올라온 것 보기 → 몇 장 넘겨 보기 → 닫기". 올리기는 일주일에 2~3번 몰아서. 빈도: 타임라인 보기 > 뷰어 > 올리기 > 앨범 > 검색 > 휴지통 > 설정.

## 3. 기능 목록

| ID | 기능 | 설명 |
|---|---|---|
| F1 | 기기 등록 | 계정·비밀번호 없음. 초대 QR 또는 초대 코드로 처음 한 번 등록 |
| F2 | 올리기 | 갤러리에서 여러 장 선택 / 다른 앱의 공유 시트에서 "우리사이에 올리기". 사진·동영상 |
| F3 | 업로드 진행 | 올리는 중인 항목이 타임라인에 바로 보이고(진행률), 앱을 닫아도 이어서 올라감. 실패는 눈에 보임 |
| F4 | 타임라인 | 촬영일 기준 하나의 타임라인, 월·일 묶음. 누가 올렸는지 보임. 3열/5열 |
| F5 | 상대가 새로 올린 것 | 앱을 열면 지난번 이후 상대가 올린 사진이 눈에 걸린다(알림 대신) |
| F6 | 뷰어 | 사진 크게 보기·넘기기·확대, 동영상 바로 재생, 정보 보기 |
| F7 | 앨범 | 한 사진이 여러 앨범에 들어갈 수 있음(태그처럼). 누구나 만들고 이름 바꾸고 지움 |
| F8 | 검색 | 글자로 검색("바다", "케이크") + 기간·올린 사람·앨범·사진/동영상 거르기 |
| F9 | 지우기·휴지통 | 누구나 지움(알림 없음), 14일 보관 후 자동 삭제, 누구나 되살림 |
| F10 | 갤러리에 저장 | 원본 화질로 내 폰에 저장 |
| F11 | 설정 | 내 이름, 등록된 기기 보기·해제, 새 기기 추가, 에이전트 연결 토큰 |

### 의도한 결정 — 바꾸지 않음

- **지워도 상대에게 알리지 않는다.** 대신 휴지통에 "누가 지웠는지" 가 남는다.
- **휴지통을 즉시 비우는 기능은 없다.** 14일이 지나야만 사라진다. 실수 삭제를 되돌릴 시간을 보장하기 위해서.
- **에이전트는 지우거나 되살릴 수 없다.** 찾기·올리기·앨범에 넣기만.

### 비목표 — 만들지 않음

하트·댓글·푸시 알림 같은 사진 외 대화(메신저가 한다), 카메라롤 자동 백업, 지도 보기(위치는 정보에 글자로만), 두 사람 외 사용자 초대, 오프라인 사용, 이별 시 데이터 처리.

## 4. 화면별 명세

> 번호는 편의상. 합치거나 나눠도 되지만 표시 요소와 정책은 빠지면 안 됩니다.

### S01. 첫 화면 — 초대 받기
- **진입**: 앱 처음 실행(등록 안 된 기기)
- **표시**: 앱 이름 "우리사이", 한 줄 소개("둘만 보는 앨범"), "초대 QR 스캔", "초대 코드로 등록"
- **동작**: QR 스캔 → 카메라 → 인식되면 S03 / 코드 → S02
- **정책**: 초대는 상대 폰의 설정 > 새 기기 추가에서 만든다(S17). 카메라 권한 거부 시 코드 입력으로 안내. 초대 링크(문자·카톡으로 받은 링크)를 누르면 이 화면을 건너뛰고 S03.

### S02. 초대 코드 입력
- **진입**: S01 "초대 코드로 등록"
- **표시**: 10자리 코드 입력칸(예: `ABCDE-FGHJK`, 대문자 자동), 등록
- **정책**: R1·R2.

### S03. 이름 확인
- **진입**: 등록 성공 직후, 설정 > 내 이름
- **표시**: "우리사이에서 쓸 이름"(초대할 때 정해진 이름이 채워져 있음), 내 아바타 미리보기, 시작하기
- **정책**: 이름은 사진의 "올린 사람" 표시와 휴지통의 "지운 사람" 에 쓰인다. 2~10자.

### S04. 타임라인 (홈)
- **진입**: 앱 실행(등록된 기기) — 1초 안에 지난번 화면이 보여야 함
- **표시**
  - 상단: 앨범 이름("수민 ♡ 지윤" 같은 둘의 공간 이름), 검색, 올리기(+)
  - **상대가 새로 올린 것**: 지난번 열어 본 뒤 상대가 올린 묶음 — "지윤이 어제 32장 올렸어요" 처럼, 누르면 그 묶음 위치로. 다 보면 사라짐
  - 업로드 중인 항목: 맨 위 묶음에 바로 끼어 있음(진행률 표시), 실패한 항목은 표시 + 다시 시도
  - 월·일 묶음 헤더("2026년 10월" / "10월 4일 토"), 촬영일 기준
  - 정사각 썸네일 그리드. 칸마다 **올린 사람**(작은 글자 아바타), 동영상은 길이("0:42"), 에이전트가 올린 것은 "via" 표시
  - 올린 사람 거르기: 전체 / 수민 / 지윤
- **동작**: 썸네일 → S06 / 길게 누르기 → S05(여러 장 선택) / + → S09 / 두 손가락 오므리기·벌리기로 3열 ↔ 5열
- **정책**: 촬영일 없는 항목은 올린 날로. 아직 안 받아진 칸은 흐린 미리보기로 즉시 채움(빈 칸 금지). 사진이 0장이면 올리기 유도(R12). 당겨서 새로고침. 3,000장 넘게 쌓여도 끊기지 않게 스크롤.

### S05. 여러 장 선택
- **진입**: 타임라인·앨범 상세에서 길게 누르기
- **표시**: 선택 개수("12장 선택"), 체크된 썸네일, 하단 동작: 앨범에 넣기 / 갤러리에 저장 / 지우기
- **동작**: 지우기 → R6 / 앨범에 넣기 → S08
- **정책**: 날짜 헤더 누르면 그날 전체 선택.

### S06. 사진 보기
- **진입**: 타임라인·앨범 상세·검색 결과의 썸네일
- **표시**: 사진 전체 화면, 상단에 올린 사람·촬영 날짜, 하단 동작: 공유 / 앨범에 넣기 / 갤러리에 저장 / 지우기 / 정보
- **동작**: 좌우로 넘기기, 두 번 탭·벌리기 확대, 아래로 끌어 닫기. 정보 → S07
- **정책**: 탭하면 0.5초 안에 보여야 함(흐린 미리보기 → 선명). 지우면 다음 사진으로 넘어가고 "휴지통으로 옮겼어요 · 되돌리기" 가 잠깐 뜸.

### S07. 정보 시트
- **진입**: 사진·동영상 보기 > 정보
- **표시**: 올린 사람(에이전트면 "수민 (via SimpleClaw)"), 촬영 일시, 올린 일시, 해상도·용량, 위치(좌표 글자, 있을 때만), 들어 있는 앨범, 자동으로 붙은 설명("바닷가에서 웃는 두 사람의 뒷모습" 같은 한 줄 — 검색에 쓰임)

### S08. 앨범에 넣기 시트
- **진입**: 사진 보기, 여러 장 선택
- **표시**: 앨범 목록(이미 들어 있는 앨범은 체크), 맨 위 "+ 새 앨범"
- **정책**: 여러 앨범 동시 선택 가능. 새 앨범 만들기는 이름 입력 후 바로 체크된 상태로.

### S09. 올리기 — 사진 고르기
- **진입**: 타임라인 +, 앨범 상세 +
- **표시**: 폰 갤러리(시스템 선택기), 고른 개수, 올리기. 앨범 상세에서 왔으면 "제주 2025에 넣기" 가 켜진 상태
- **정책**: 갤러리 권한 거부 시 시스템 설정 안내(R11). Live Photo는 정지 사진으로. 한 번에 최대 200장.

### S10. 다른 앱에서 공유로 올리기
- **진입**: 갤러리·카톡 등에서 공유 → "우리사이"
- **표시**: 고른 사진 미리보기(개수), 넣을 앨범(선택), 올리기
- **동작**: 올리기 → "올리기 시작했어요" 후 원래 앱으로 돌아감. 진행은 S11에서
- **정책**: 등록 안 된 기기면 "먼저 우리사이 앱에서 초대를 받아 주세요".

### S11. 업로드 진행 시트
- **진입**: 타임라인 업로드 중 표시 누르기, 공유로 올린 뒤 앱 열기
- **표시**: 전체 진행("24장 중 18장"), 항목별 상태(대기 / 올리는 중 % / 영상 준비 중 / 완료 / 건너뜀 / 실패), 실패 항목 "다시 시도", "앱을 닫아도 계속 올라가요"
- **정책**: R3·R4·R5. 동영상은 올리기 전에 폰에서 재생용으로 변환해서 시간이 더 걸림(발열 가능) — "영상 준비 중".

### S12. 동영상 보기
- **진입**: 동영상 썸네일
- **표시**: 탭 즉시 재생, 탐색 막대, 길이, 음소거, 사진 보기와 같은 상단·하단 동작
- **정책**: 1초 안에 재생 시작. iPhone으로 찍은 HDR 영상도 Android에서 색 빠짐 없이 재생(재생용 사본). 갤러리 저장은 원본으로.

### S13. 앨범 목록
- **진입**: 하단 탭 "앨범"
- **표시**: 앨범 카드(대표 사진, 이름, 장수, 마지막 추가일), "+ 새 앨범"
- **정책**: 앨범 0개면 첫 앨범 만들기 유도(R12). 정렬은 최근 추가순.

### S14. 앨범 상세
- **진입**: 앨범 목록
- **표시**: 앨범 이름·장수·만든 사람, 그리드(타임라인과 같은 모양), +(이 앨범에 올리기), 더보기: 이름 바꾸기 / 앨범 지우기
- **정책**: 앨범 지우기는 사진을 지우지 않음(R7). 앨범에서 빼기는 사진을 지우지 않음 — 여러 장 선택의 "앨범에서 빼기".

### S15. 검색
- **진입**: 타임라인 검색, 하단 탭 "검색"
- **표시**: 검색칸("바다, 케이크, 눈 오는 날…"), 거르기 칩(기간 / 올린 사람 / 앨범 / 사진·동영상), 검색 전에는 최근 검색어와 앨범 바로가기, 결과 그리드 + 개수
- **정책**: 글자 검색은 자동으로 붙은 설명으로 찾는다. 막 올린 사진은 설명이 붙기 전이라 몇 분간 글자 검색에 안 잡힐 수 있음(R9). 결과 0건(R12).

### S16. 휴지통
- **진입**: 설정 > 휴지통, 앨범 탭 하단 "휴지통"
- **표시**: 맨 위 "지운 사진은 14일 뒤 자동으로 사라져요", 항목마다 "지윤이 지움 · 3일 후 삭제", 여러 장 선택 → 되살리기
- **동작**: 항목 누르기 → 크게 보기 + 되살리기 / 되살리기 → 원래 자리(타임라인·원래 앨범)로
- **정책**: R6·R8. 영구 삭제 버튼 없음(의도). 휴지통이 비면 R12.

### S17. 설정
- **진입**: 타임라인 상단 또는 하단 탭
- **표시**
  - 내 이름(→ S03)
  - **등록된 기기**: 기기 이름(예: "수민의 Galaxy S24", "지윤의 iPhone 15"), 등록일, 마지막 사용, "해제"

## 5. 화면에서 부딪히는 규칙

> 화면 명세와 겹쳐도 이쪽이 기준입니다.

- **R1. 초대 코드 형식**: 10자리(영문 대문자·숫자, 가운데 하이픈은 있어도 없어도 됨). 형식이 틀리면 입력칸 바로 아래 "초대 코드는 10자리예요 (예: ABCDE-FGHJK)".
- **R2. 초대 만료·사용됨**: 초대는 만든 뒤 **24시간**, **한 번만** 쓸 수 있다. 만료·이미 사용된 코드면 "이 초대는 만료됐어요. 상대 폰의 설정 > 새 기기 추가에서 다시 만들어 주세요".
- **R3. 같은 사진 다시 올리기**: 이미 올라간 것과 **내용이 똑같은 파일**은 건너뛴다. 진행 시트에 "이미 있는 사진 5장은 건너뛰었어요" — 실패가 아님.
- **R4. 업로드 실패**: 네트워크·용량 등으로 실패하면 자동으로 다시 시도하고, 그래도 안 되면 **타임라인 해당 칸과 진행 시트에 실패 표시 + 다시 시도**. 조용히 사라지는 실패는 없다.
- **R5. 앱을 닫아도 계속**: 올리는 중 앱을 닫거나 전화가 와도, 다시 열면 남은 것부터 이어서 올린다.
- **R6. 지우기**: 누구나 누구의 사진이든 지울 수 있다. 지우면 휴지통으로 가고 **상대에게 알림은 없다.** 여러 장 지울 때는 "12장을 휴지통으로 옮길까요? 14일 동안 되살릴 수 있어요" 확인. 상대가 올린 사진이 섞여 있으면 "지윤이 올린 사진 4장 포함" 을 같이 보여 준다.
- **R7. 앨범 지우기**: 앨범만 사라지고 사진은 그대로. 확인 대화상자에서 "사진 48장은 지워지지 않아요".
- **R8. 휴지통 보관**: 지운 날부터 **14일 뒤 자동 영구 삭제**, 즉시 비우기 없음. 남은 날은 "3일 후 삭제", 마지막 날은 "오늘 밤 삭제". 되살리면 원래 앨범에도 다시 들어간다. 둘이 동시에 같은 사진을 지우거나 되살리면 마지막 동작 기준.
- **R9. 자동 설명 대기**: 올린 직후 몇 분은 설명이 없어 글자 검색에 안 잡힌다. 검색 결과 아래 "방금 올린 사진은 몇 분 뒤부터 검색돼요".
- **R10. 기기·토큰 해제**: 해제하면 그 기기(또는 에이전트)는 즉시 앨범을 볼 수 없다. 되돌릴 수 없어서 확인 대화상자. **지금 쓰는 이 기기는 해제할 수 없다**(목록에 "이 기기" 표시). 새 토큰은 한 번만 보이므로 "지금 복사해 두세요".
- **R11. 권한 거부**: 카메라 거부 → 초대 코드 입력으로. 갤러리 거부 → 올리기 불가 + 시스템 설정 열기. 갤러리 저장 권한 거부 → 저장 불가 + 설정 열기.
- **R12. 빈 상태**: 첫 타임라인("첫 사진을 올려 보세요" + 올리기), 앨범 0개, 검색 0건("다른 말로 찾아보거나 거르기를 풀어 보세요"), 휴지통 비어 있음.
