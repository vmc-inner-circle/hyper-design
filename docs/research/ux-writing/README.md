## 핵심 결론: "명사형이냐 해요체냐"가 아니라 "그 자리가 무슨 일을 하는가"

출처들은 겉으로 충돌한다 — 토스는 "모든 문구에 해요체", "카드 연결 완료는 Don't"라 하고, 당근·MS·실제 앱은 라벨·배지·섹션 제목을 명사로 쓴다. 자리의 역할로 나누면 모두 맞아떨어진다.

| 역할 | 자리 | 형태 | 근거 | 왜 |
|---|---|---|---|---|
| **이름표** — 무엇이 어디 있는지 가리킨다 | 앱바·섹션 제목, 행 제목(데이터 이름), 라벨, 탭, 배지, 칩, 토글, 큰 숫자의 라벨 | **명사구.** 마침표 없음 | 당근 SEED(입력 라벨·칩·배지·배너 제목 명사, 탭 5자 이내), 토스(데이터 라벨 「남은 대출금」, 섹션 「자주 묻는 질문」), 실제 섹션 제목 35개 중 명사구 33·조건절 0, 번역 앱도 제목·버튼 55~90% 명사형, MS(제목 명사구), 카카오 문서 가이드(정보 제목은 명사, 행동 제목은 `~하기`) | 사람은 이름표를 **읽지 않고 훑는다**. 명사가 앞에서 끝나야 한눈에 잡히고, 버튼 → 열리는 화면 제목 → 결과 배지가 같은 명사를 공유할 수 있다(예약하기 → 예약 → 예약 완료). **우리 실패는 이 넷 중 어디에도 속하지 않는 "조각"이다.** `자리가 나면`은 이름표도 말도 아니라 영어 헤딩 구조를 옮긴 절 조각이고, `내 순번은 5번`은 주제 조사로 시작한 말을 숫자에서 끊었다. 실제 앱은 `빈자리 알림`(이름표) + 그 아래 사실 행으로, `나의 순서` / `5번째`(라벨 + 숫자 두 줄)로 쓴다.

## 쟁점별 판단

1. **해요체 vs 합니다체** — 토스·당근은 해요체(일관성·브랜딩), 리디·삼성은 합니다체("해요체는 신뢰가 떨어져 보일 수 있다"). **모두 섞지 말라는 데는 일치한다.** 하네스는 지금처럼 해요체로 통일한다(국내 대중 앱 다수, 당근은 주의가 필요한 자동 메시지에만 합니다체).
2. **"~할 수 있어요"는 금지가 아니다** — 토스는 강요(「~해야 해요」) 대신 권유로 **권장**하고, 당근도 쓴다. 번역투로 읽히는 것은 `~하실 수 있습니다`(경어 겹침), `사용 가능합니다`(한자어 명사)다. 실제로 이 문형은 앱 화면보다 **App Store 설명문**에 몰려 있다(당근 13·토스 12·테이블링 11회 vs 화면 안 3건) — 우리 화면이 소개서처럼 읽히는 이유. → 해결책·기회를 알릴 때만 쓰고, 화면이 하는 일을 설명하는 데 쓰지 않는다.
3. **줄표(—)로 두 문장 잇기** — 한글 맞춤법에서 줄표는 부제·삽입구용이다. 국내 화면·코드 0건, 번역 앱에서만 15건. MS 가이드도 영어 em dash를 연결어미·관형절로 푼다. → 제목 + 본문으로 나누거나 `·`로 사실을 잇는다.
4. **명사+명사 한자어 묶음** — 토스는 문장 안에서 금지(「잔액 부족으로」 → 「잔액이 부족해서」). 네이버파이낸셜은 쉬운 말 사전을 둔다(가입일 → 가입한 날, 송금 → 돈 보내기, 경우 → ~하면/~때). 그러나 사실 줄에서는 배민·캐치테이블이 `~ 시`를 쓴다. → **문장(말) 안에서는 풀어 쓰고, 사실 줄(·로 잇는 곳)에서는 압축을 허용**한다.
5. **대명사·소유** — Apple: 「Your Favorites」보다 「Favorites」. 국립국어원 논문: 번역문의 당신·그것은 영어가 주어를 요구해서다. 국내 코드의 "당신" 0회. 단 `내 예약`·`나의 순서`처럼 메뉴·라벨의 "내/나의"는 실제 앱이 쓴다. → "당신" 금지, "내"는 이름표에서만.
6. **경어** — 토스: 「해지하시겠어요?」 → 「해지할까요?」, 계시다·여쭈다·께 금지. 리디: `-시-`는 마지막 동사에만. 호칭은 「○○님」, 「고객님」은 어느 출처에도 없다.
7. **번역투 표지 어휘** — `~로 인한`, `~을 통해`, `~이 가능하며`, `~에 대한`, `~로부터`, `~에 의해`, `수행`, `제공`, `가지다`, `되어지다`·`보여지다`, `유효하지 않은 X입니다` → `X를 다시 확인해 주세요`(토스·국립국어원·MS·SKT).
8. **날짜·숫자** — 네이버파이낸셜이 금지 형식을 표로 둔다(`22/04/02`, `2021-5-31`, `05.30`). 당근은 아라비아 숫자(「1개」, 「2일 뒤」), 배민은 「1만원」. → 하네스의 사실 표 형식(`10월 15일(목) 20:00`)을 유지하고 앱 안에서 한 형식만.
9. **마침표** — 당근: 제목·20pt 이상·버튼·메뉴·라벨에는 없음, 토스트는 한 문장이면 없음, 두 문장이면 모두. 토스: 제목 없음, 본문 있음. 리디만 한 줄 메시지에도 찍는다 — 다수 쪽을 따른다.
