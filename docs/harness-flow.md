# 하네스 플로우 — PRD를 넣으면

사용자는 **네 번** 개입합니다(한도 5회). 시간은 셀프 테스트에서 잰 값이에요.

**시작**: 새 세션에서 PRD만 넣습니다. 예: `/design-harness prd/family-trip.md`, 또는 PRD 내용을 그대로 붙여넣기. PRD 파일은 고치지 않고 그대로 넣어요. **(개입 1)**

## 1턴: PRD → 시안 고르기 보드 (약 8~13분)

1. **레퍼런스 조사 5곳**(백그라운드, 약 1분): 국내 · 해외 · 다른 분야 · 같은 사용자층이 쓰는 앱 · 디자인 갤러리
2. **PRD 분석**(동시에): 역할, 화면 목록, 흐름, 갈래(흐름 밖 버튼이 여는 화면·창)
3. **시안 5개 정하기**: 메뉴 구조, 첫 화면 구성, 밀도, 분위기가 서로 다르게. 시안마다 참고한 서비스를 적습니다.
4. **시안 화면 만들기**: 시안마다 메인 화면 3~6장을 작업 묶음(팩)과 조립 에이전트 최대 10개로 동시에 만듭니다(에이전트당 약 2분).
5. **검사 → 브라우저에 자동으로 띄우기**

→ **사용자**: 시안 하나를 고르고, 다른 안에서 가져올 점은 그 안의 칸에 적은 뒤 복사해서 붙여넣기 **(개입 2)**

## 2턴: 고른 시안으로 초안 (약 6분)

- 고른 시안의 메인 화면은 그대로 옮기고, 나머지 화면은 같은 모양으로 새로 만듭니다.
- **초안 보드**가 뜹니다.
  - **사용 흐름**: 흐름 카드 → 두 장씩 따라가기. 갈래는 보라 점선으로 보여요.
  - **화면 디자인**: 아무 요소나 골라 의견을 남겨요.
  - **화면 느낌**: 분위기, 글자 크기, 버튼 색을 골라요.

→ **사용자**: 고칠 곳을 골라 의견을 남기고 "의견 보내기"로 복사해서 붙여넣기 **(개입 3)**

## 3턴: 의견 반영 → 최종본 (약 2~5분)

- 작은 수정은 가벼운 모델(haiku), 배치를 바꾸는 수정은 sonnet이 고칩니다.
- **최종본**: `index.html`(화면 전체 캔버스와 사용 흐름) + 화면별 완성본 페이지(버튼을 누르면 다음 화면으로)
- `submissions/srlee0408/`에 결과물, `prompt-log.md`, `elapsed.txt`를 복사합니다.

→ **사용자**: "이대로 제출할까요?"에 답하기. 고칠 게 있으면 같은 답에 붙여넣기 **(개입 4)**

## 4턴: 제출 확인

- "이대로 제출"이면 끝입니다.
- 의견이 붙어 오면 반영해서 다시 제출하고, 더 묻지 않고 끝냅니다. 5번째 개입은 사고 났을 때를 위한 여유분이에요.

**예외**: PRD가 애매해서 잘못 짐작하면 화면 대부분을 다시 만들어야 하는 경우에만, 1턴 전에 객관식 질문을 한 번 합니다(3개 이하). 그러면 여유분이 없어지므로 정말 필요할 때만 해요.
