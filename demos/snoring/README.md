# 데모 · 드르렁 (코골이 측정 앱)

`prd/snoring.md`로 design-harness(`sprint/designer-taste`, #23)를 1~3턴 자동으로 돌린 결과입니다. 사용자 답은 하네스가 추천값으로 대신 했습니다.

| 열어 볼 파일 | 무엇 |
|---|---|
| `결과-모아보기.html` | 한 파일에 1턴 시안 보드 · 2턴 초안 보드 · 3턴 최종본 · 화면 21장을 탭으로 |
| `out/index.html` | 최종본 입구 — 사용 흐름(구역 보드) · 흐름 재생 · 화면 전체 |
| `out/screens/*.html` | 화면별 완성본(버튼을 누르면 다음 화면, 안내 문구·움직임) |
| `out/board.html` | 2턴 초안 보드(사용 흐름 · 흐름 재생 · 화면 디자인 · 안내 문구 모음) |

기록: `prompt-log.md`(개입 3회) · `elapsed.txt`(약 11분) · `brief.md`(가정 로그) · `references.md`(살펴본 서비스) · `harness-notes.md`(이 테스트에서 하네스를 고친 것) · `screens.json` · `flow.json`
