# AI 사주 앱 "결" — 기획 브리프 v0.3

> 작성: 서비스기획 PM / 최종 수정: 2026-10-06 / 상태: 디자인 의뢰용 초안
> "무엇을" 만들지 정리한 문서입니다. "어떻게 보일지"는 제안을 받고 싶습니다. 미확정 사항은 6장에 모았습니다.

---

## 1. 서비스 개요

생년월일시만 넣으면 **내 사주를 AI가 쉬운 말로 풀어 주고, 궁금한 것을 바로 물어볼 수 있는** 모바일 앱입니다.

기존 사주 앱은 두 갈래입니다. ① 무료 앱은 "갑목(甲木) 일간, 편관격…" 같은 한자 용어를 늘어놓아 읽어도 무슨 말인지 모르고, ② 역술가 상담은 1회 3~5만 원에 예약까지 며칠이 걸립니다. 사용자는 "그래서 나 이번에 이직해도 돼?"처럼 **자기 상황에 맞는 한 문장 답**을 원합니다.

| 구분 | 설명 | MVP 범위 |
|---|---|---|
| 사용자 | 내 사주 보기, 오늘의 운세, AI에게 질문, 궁합 | **이번 범위 (모바일 앱)** |
| 운영자 | 해석 문구 검수, 신고 처리, 정산 | 범위 외 — 내부 어드민 |

iOS/Android, 세로 화면 기준.

## 2. 우리가 해결하고 싶은 문제

1. **용어가 어렵다** — 오행·십신·대운을 모르면 결과 화면을 읽을 수 없음. 앱 리뷰 1위 불만 "뭔 소린지 모르겠다".
2. **내 상황에 대한 답이 없다** — 일반론("올해는 변화의 해")만 있고 "지금 다니는 회사 버틸까?"에는 답하지 않음.
3. **매일 열 이유가 없다** — 한 번 보고 지움. 30일 리텐션 8%(경쟁 앱 추정).
4. **궁합은 혼자 보기 아깝다** — 연인·친구에게 보여 주고 싶은데 캡처 말고는 방법이 없음.
5. (부가) **AI 답이 단정적이면 위험** — 건강·투자·법률을 단정하면 분쟁 소지. 선을 지켜야 함.

## 3. 타깃 사용자와 사용 맥락

**A. 한소윤 (27세, 여, 취업 준비 2년 차)** — 최종 면접을 앞두고 불안. 친구가 보내 준 궁합 링크로 처음 설치. 사주 용어는 하나도 모름.
- 자기 전 침대에서 오늘의 운세·내일 운세 확인
- "이번 달 면접 운 어때?"를 AI에게 물어봄
- 남자친구와 궁합을 보고 결과를 카톡으로 보냄

**B. 정우진 (35세, 남, IT 회사 8년 차)** — 이직 제안을 받고 고민 중. 사주를 믿진 않지만 "참고로" 보고 싶음. 근거 없이 단정하는 말을 싫어함.
- 출근길에 내 사주 풀이를 처음부터 읽어 봄 (왜 그렇게 말하는지 근거가 궁금)
- 연봉·이직 시기를 AI에게 구체적으로 질문

**C. 김미경 (56세, 여, 자영업)** — 딸(한소윤 또래)의 결혼 상대가 궁금. 글자 크기에 민감하고, 결제는 신중함.
- 딸과 예비 사위의 생년월일을 넣어 궁합 확인
- 신년운세(2027)를 가족 것까지 구매

**공통**: 1회 사용 2~5분. 저녁·밤 사용이 대부분. 예상 빈도: 오늘의 운세 > AI 질문 > 내 사주 풀이 > 궁합 > 신년운세 구매.

## 5. 화면별 명세

### S01. 시작하기
- **표시**: 서비스 소개 한 장("생년월일만 넣으면, 내 사주를 쉬운 말로"), 카카오로 시작, Apple로 시작, 약관 링크
- **정책**: 만 14세 미만은 가입 불가(R1). 친구가 보낸 궁합 링크로 들어왔으면 가입 후 그 궁합 결과로 바로 이동.

### S02. 생년월일시 입력 (2단계)
- **1단계**: 이름(닉네임), 성별, 생년월일, 양력/음력(음력이면 윤달 여부)
- **2단계**: 태어난 시간(12지시 선택 또는 시:분), "시간을 몰라요", 태어난 곳(선택 — 시간 보정용)
- **정책**: 시간을 모르면 시주(時柱) 없이 풀이하고, 결과 화면에 "태어난 시간을 넣으면 더 정확해져요"를 한 번 표시(R2). 미래 날짜·존재하지 않는 음력 날짜는 오류(R3). 입력 후 수정 가능, 단 수정하면 지난 AI 답은 "이전 정보 기준"으로 표시.

### S03. 홈 (오늘)
- **표시**: 오늘 날짜(양력·음력·일진), 오늘의 한 줄, 총운·일·돈·관계 점수, 행운의 색·숫자, 추천 질문 2~3개, 내 사주 풀이 바로가기, 궁합 보기, 신년운세 배너(10~1월)
- **정책**: 첫 방문엔 "내 사주 풀이"가 가장 먼저 보였으면 함(아직 내 사주를 모름). 둘째 날부터는 오늘의 운세가 먼저.

### S04. 내 사주 풀이
- **표시**: 사주 원국 8글자 표(천간·지지, 오행 색), 오행 분포(목·화·토·금·수 개수), AI 풀이 4개 장(성격 / 일·커리어 / 돈 / 관계), 지금 대운(10년 단위) 한 줄, 용어에 밑줄 → 누르면 뜻
- **정책**: 풀이는 한자 용어 없이 먼저 말하고, 용어는 근거로만. 시간 모름이면 원국 표에 시주 칸을 "모름"으로.

### S05. AI에게 묻기 (채팅)
- **표시**: 추천 질문 칩(일·연애·돈·건강 제외), 입력창, 답변, 답마다 "근거 보기"(관련 기운·대운), 남은 무료 질문 수
- **정책**: 하루 무료 질문 3회, 이후 1회 별 5개(R4). 별 부족 시 충전으로(R5). 건강·투자·법률 질문엔 단정하지 않고 "전문가와 상의" 문구(R6). 답변은 300자 이내.

### S06. 궁합 — 상대 입력
- **표시**: 저장된 사람 고르기 또는 새로 입력(이름, 관계: 연인·배우자·가족·친구·동료, 생년월일, 시간), 관계에 따라 풀이 관점이 바뀜
- **정책**: 상대 정보는 내 기기·계정에만 저장, 상대에게 알리지 않음. 같은 상대 궁합은 다시 보기 무료.

### S07. 궁합 결과
- **표시**: 궁합 점수(100점), 한 줄 요약, 잘 맞는 점 3 / 부딪히는 점 3 / 이렇게 해 보세요 2, 두 사람 오행 비교, 공유하기(링크 — 받은 사람은 점수와 요약만 보고 자세한 건 가입 후)
- **정책**: 공유 링크에는 생년월일을 노출하지 않음(R7). 링크 유효 30일.

### S08. 신년운세 리포트 (2027)
- **표시**: 미리보기(올해의 한 단어, 1~2월 흐름), 누구 것을 살지(나 / 저장된 사람), 가격 9,900원(별 99개), 구매 후 월별 12장 리포트
- **정책**: 열람 후 환불 불가 — 구매 전 명시(R8). 같은 사람 리포트 중복 구매 막음(R9).

### S09. 별 충전 / 사용 내역
- **표시**: 보유 별, 상품(별 30개 3,300원 / 100개 9,900원 / 300개 27,000원), 결제 수단(앱 내 결제), 사용 내역
- **정책**: 결제 실패 시 다시 시도 안내. 충전 완료 후 원래 하던 일(질문·리포트)로 돌아감.

### S10. 지난 기록
- **표시**: 탭 — 질문 / 궁합 / 리포트. 날짜순, 질문은 첫 줄 미리보기.
- **정책**: 질문 기록은 1년 보관.

### S11. 마이·설정
- **표시**: 내 생년월일시(수정), 저장한 사람 목록(추가·수정·삭제), 운세 알림 시간, 결제 내역, 로그아웃·탈퇴
- **정책**: 저장한 사람 삭제 시 그 사람 궁합·리포트 기록도 지울지 묻기(R10).

## 6. 논의 중
1. 오늘의 운세 점수를 숫자로 보여 줄지(불안 유발 우려) — 디자인 제안 받고 결정
2. 무료 질문 3회가 적당한지
3. 공유 링크 받은 사람의 첫 화면을 어디까지 열어 줄지
4. 캐릭터·일러스트 톤 — 무속 느낌(붉은 부적·한지)은 피하고 싶음
