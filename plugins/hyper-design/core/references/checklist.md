# 비평 체크리스트 — 캡처를 볼 때(P0·P1이면 반드시 고친다)

- **대상마다 시작과 끝이 있는가** — 처음 만드는 화면(빈 상태에서 출발), 완료 확인, 지난 기록, 탭의 각 칸 (P0, 치명적)
- 탭 첫 화면·홈에 하단 고정 버튼이 있는가 / 문구가 "~보기"인가 (P1)
- 사용자에게 새 할 일(보내기·정리)을 얹는 기능이 있는가 (P1)
- 사람을 역할 이름으로 부르는가 (P1)
- 뜻이 다른 배지가 같은 색인가 (P1)
- 채워진 버튼에 짙은 글자인가 / 버튼이 버튼처럼 안 보이는가 (P1)
- 누른 뒤 갈 곳이 없는 버튼, 빈 상태가 결과 있는 것처럼 보이는 목록, 링크·초대 뒤 결과 표시 없음 (P0)
- 하단 고정 버튼이 스크롤 끝의 마지막 내용을 가린다 (P1)
- 선택 상태가 두 모양(검정/브랜드)이다, 시간·순서를 배지로 썼다 (P1)
- PRD 동사(추가·순서 바꾸기·지우기)에 조작 수단이 없다 (P1)
- 오류·안내 문구가 화면에 없는 선택지를 가리킨다 (P0), 한 번뿐인 행동(요청·확인)의 눌린 뒤 모습이 없다 (P1)
- 화면끼리 같은 사실(날짜·겹침·인원·상태 이름)이 다르다 / 결정 화면에서 core 정보(예: 겹침)가 사라진다 (P1)
- 수십 개 목록에 검색이 없다 / 사용자가 만드는 분류를 만들 곳이 없다 (P0~P1)
- 명세 화면·단계가 빠졌다 / 규칙 상태가 규칙을 보여 주지 않는다 (P0~P1)
- 사진 자리가 회색 박스·글자뿐이다 / 사진이 내용과 안 맞는다 (P1)
- confirm 대화상자를 되돌릴 수 있는 행동에 썼다 / 지우기 같은 위험한 확인 버튼이 브랜드 채움이다(→ 오류 색 글자) (P1)
- 세그먼트·탭을 눌러도 아래 목록이 그대로다(구역을 다 이어 붙임) — 한 탭의 내용만 보여 준다 (P1)
- 같은 숫자(잔여 횟수·인원·금액)가 화면마다 다르다 (P1)
- 지도 화면에 핀·위치 표시가 없다 (P1)
- 설명 카드("~를 누르면 ~돼요")가 반복된다 — 화면당 부가 설명 1개, 조작법 설명 금지 (P1)
