# 보이스톤 프리셋

앱 9개의 실제 본앱 문구 지문(`docs/research/ux-writing/real/README.md`)에서 가장 크게 갈린 두 묶음. 회사가 아니라 **실제로 갈리는 말투**가 단위다.

| 파일 | 사용자에게 보일 이름 | 근거 앱 | 맞는 앱 |
|---|---|---|---|
| `haeyo.json` (기본) | 짧고 담백하게 | 토스·당근·배민·오늘의집·캐치테이블 | 대부분의 생활·커머스·예약·커뮤니티 |
| `hamnida.json` | 정중하게 | 리디·무신사·KB스타뱅킹·정부24 | 금융·공공·보험·의료·계약, 무거운 결제, 높은 연령 |

- 공통 문법(이름표 명사구·번역투 금지·줄표 금지)은 프리셋과 무관하게 항상 지킨다.
- `pairs`는 공개 가이드 원문 출처만. 실제 앱 문구(정답지)는 넣지 않는다 — 검증 시험지다.
- `sources/`: 회사별 가이드를 옮긴 1차 프리셋(토스·당근·리디). 회사 단위로는 '보이스톤 없음'보다 실제 문구에 가깝지 않았다(`loop/voicetone/SUMMARY.md`) — 근거 자료로만 둔다.
- 검증: `loop/realness_eval.py` — 같은 뜻의 실제 앱 문구와 나란히 놓고 구별되는가(0.5에 가까울수록 좋다).
