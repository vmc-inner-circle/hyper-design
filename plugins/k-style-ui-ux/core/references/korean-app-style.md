# 한국 대중 앱 스타일 — v8부터 파운데이션으로 대체

v7까지 이 문서가 골격 수치(제목 26px, 본문 17px 등)와 무드 시안 3종(토스·카카오·29CM처럼)을 정했다. v8에서는:

- **수치·클래스**는 `foundation/derive.py`(토큰) + `foundation/components.css`(부품) + `foundation/COMPONENTS.md`(사용법)가 유일한 출처다.
- **색**은 무드 질문 대신 실제 국내 서비스 팔레트 라이브러리(`foundation/palettes/`)에서 하네스가 기본 1 + 대안 2를 정하고, 캔버스에서 원클릭으로 바꾼다.

## 여전히 유효한 "하지 말 것"

- 흰 바탕에 구분선만 이어지는 화면(섹션 리듬 없음)
- 탁한 색(채도를 죽인 벽돌색·올리브색)
- 테두리 박스 버튼 남발, 선택 탭에 박스
- 작은 제목으로 시작하는 홈
- 채워진 버튼 위 짙은 글자(노랑처럼 아주 밝은 색 제외)
