# 보이스톤 프리셋

공개된 UX 라이팅 가이드에서 옮긴 회사별 보이스톤. 근거와 종합은 `docs/research/ux-writing/`.

**프리셋은 회사마다 다른 것만 담는다** — 문체·경어·자리별 형태·버튼 쌍·감정 강도·밀도·어휘·표기, 그리고 출처가 있는 before → after → 이유 예시 쌍. "이름표는 명사구", "줄표로 문장 잇기 금지" 같은 공통 문법은 프리셋과 무관하게 항상 지킨다(어떤 프리셋을 골라도 직역투가 나오지 않게).

| 파일 | 사용자에게 보일 이름 | 맞는 앱 |
|---|---|---|
| `toss.json` | 짧고 담백하게 (토스) | 빠르게 쓰는 거래·예약·금융·생활 |
| `daangn.json` | 다정하게 (당근) | 사람이 만나는 커뮤니티·동네·모임·취미 |
| `ridi.json` | 정중하게 (리디) | 신뢰가 핵심 — 의료·계약·교육·콘텐츠 결제, 높은 연령 |

- `label`이 먼저, 회사 이름은 괄호로 — 사용자는 회사 말투를 몰라도 고를 수 있어야 한다.
- `pairs`는 출처 원문만. 지어낸 예시는 넣지 않는다(빈 자리는 `why`에 "추론"으로 표시).
- `evidence`: `official`(공개 가이드) / `observed`(화면 관찰만). 관찰만으로 만든 프리셋은 질문에서 그렇게 밝힌다.
- 팔레트와 달리 **원클릭 전환이 안 된다**(모든 문구를 다시 써야 함) — 빌드 전에 한 번 확인받는다. 팔레트와는 따로 고른다.
- 아직 하네스에 연결하지 않았다 — 효과 검증 계획은 `docs/voice-experiment.md`.
