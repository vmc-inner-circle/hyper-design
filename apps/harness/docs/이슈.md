# 공통 디자인 점검 이슈

| 영역 | 공통적으로 점검할 디자인 이슈 |
| --- | --- |
| 버튼 호버 색상 | 호버하면 갑자기 검정으로 바뀌거나, 배경과 글자색이 겹쳐 안 보임 |
| 버튼 상태 구분 | 기본·호버·선택·비활성 상태가 비슷해서 구분하기 어려움 |
| 버튼 크기 | 같은 줄의 버튼 높이·패딩·모서리 둥글기가 서로 다름 |
| 아이콘 버튼 | 아이콘 크기, 클릭 영역, 텍스트와의 간격·수직 정렬이 다름 |
| 커서 | 클릭 가능한 요소에 손모양이 없거나, 일반 클릭에 확대 커서가 나옴 |
| 이미지 맞춤 방식 | contain/cover 기준이 달라 이미지가 잘리거나 여백이 과도하게 생김 |
| 이미지 비율 | 원본 비율이 깨지거나 이미지마다 표시 영역 높이가 달라짐 |
| 썸네일 규격 | 크기·비율·간격·테두리가 영역마다 다름 |
| 썸네일 제목 배치 | 제목이 어떤 곳은 위, 어떤 곳은 옆에 있어 정렬이 어긋남 |
| 선택 표시 | 선택 테두리·배경이 약하거나 선택한 썸네일이 화면 밖에 있음 |
| 텍스트 스타일 | 같은 역할의 제목·본문·안내문에서 크기·굵기·색상이 다름 |
| 줄바꿈 | 버튼·짧은 안내문이 불필요하게 두 줄이 되거나 긴 문구가 넘침 |
| 여백·정렬 | 섹션 간격과 내부 패딩이 들쭉날쭉하고 좌우 시작선이 맞지 않음 |
| 배경색·투명도 | 패널·로딩·오버레이 배경이 같은 서비스 안에서 서로 다름 |
| 모달 크기 | 내용에 비해 지나치게 넓거나 조작부를 담기에 너무 작음 |
| 반응형 배치 | 화면이 넓어도 빈 공간만 늘고, 좁으면 요소가 겹치거나 잘림 |
| 스크롤 | 불필요한 내부 스크롤·이중 스크롤이 생기거나 마지막 항목에 접근하기 어려움 |
| 고정 요소 겹침 | 하단 생성 버튼·푸터가 옵션이나 썸네일을 가림 |
| 툴팁 | 공통 컴포넌트 대신 개별 구현을 써서 모양·위치·동작이 다름 |
| 레이어 순서 | 팝오버·툴팁이 모달 뒤로 가거나 컨테이너 경계에서 잘림 |
| 전환 안정성 | 이미지 교체 시 깜빡이거나 로딩 전후에 레이아웃이 움직임 |
| 공통 스타일 반영 | 같은 컴포넌트인데 워크숍·스냅도구·이펙트에서 다르게 보임 |
