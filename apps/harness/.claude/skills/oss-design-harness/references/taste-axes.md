# 취향 축 — 고정 5축 + 프로젝트 추가 축

각 축은 **독립적**이다. 시안은 한 번에 한 축만 바꾼다.

**사용자에게 보여줄 때는 순번이 아니라 주제로 묶는다** (초보자에게 "축 1·2"는 의미가 없다):

| 탭 이름 | 묶는 축 | 쉬운 설명 한 줄 |
|---|---|---|
| 색상 | 축 1 밝기·색온도 + 축 4 강조색 | 바탕이 어떤 톤인지, 눌러야 할 버튼은 무슨 색인지 |
| 모양·간격 | 축 3 형태 + 축 2 정보 밀도 | 카드·버튼의 모서리와 그림자, 칸 사이 간격 |
| 글자·달력(추가 축) | 축 5 타이포 + 프로젝트 추가 축 | 글자 느낌, 도메인 고유 표현 |

제작 순서는 그대로 축 번호순(앞 축 확정값을 뒤 축에 고정)이되, 허브 탭은 위 세 묶음으로 낸다. 각 축 제목 아래에 쉬운 설명(`.plain`)을 붙인다. 나머지 축은 기본값(★) 또는 앞 축에서 확정된 값으로 고정한다. 순서는 아래 그대로. 앞 축이 뒤 축의 시안 배경이 되기 때문이다.

시안 콘텐츠는 PRD의 대표 화면 하나(1단계 핵심 작업이 일어나는 화면)를 390×844 폰 프레임 안에 로우파이로 그린 것. 상단 앱바·하단 탭바(또는 하단 CTA)를 포함해 실제 앱처럼 보이게 한다. 실제 문구 대신 PRD 도메인의 그럴듯한 더미 텍스트를 쓴다. Lorem ipsum 금지.

## 축 1 — 밝기·색온도

| 시안 | 값 | CSS 힌트 |
|---|---|---|
| A ★ | 라이트, 중립 | bg #FFFFFF, surface #F5F5F7, text #111827, border #E5E7EB |
| B | 라이트, 따뜻함 | bg #FDFBF7, surface #F5F0E8, text #1F1B16, border #E7E0D4 |
| C | 다크, 차가움 | bg #0F1115, surface #181B22, text #E6E8EC, border #2A2F3A |

역추출: "눈이 편하다/피곤하다", "차갑다/따뜻하다", "밤에 쓴다" 같은 말을 그대로 기준으로 기록.

## 축 2 — 정보 밀도

| 시안 | 값 | 수치 |
|---|---|---|
| A | compact | 기본 간격 4/8, 카드 패딩 12, 목록 행 48, 본문 14px |
| B ★ | comfortable | 기본 간격 8/16, 카드 패딩 16, 목록 행 56, 본문 15px |
| C | spacious | 기본 간격 12/24, 카드 패딩 20, 목록 행 64, 본문 16px |

역추출: "빡빡하다/휑하다", "한눈에 많이 보고 싶다".

## 축 3 — 형태

| 시안 | 값 | 수치 |
|---|---|---|
| A | sharp | radius 2~4, border 1px, shadow 없음 |
| B ★ | soft | radius 8 (버튼) / 12 (카드), border 1px, shadow sm (0 1px 2px rgba(0,0,0,.06)) |
| C | round | radius 16 (카드) / pill (버튼), border 없음, shadow md (0 4px 12px rgba(0,0,0,.08)) |

역추출: "딱딱하다/부드럽다/장난감 같다".

## 축 4 — 강조색 성격

| 시안 | 값 | 예 |
|---|---|---|
| A ★ | 차분한 단일 강조 | accent #2563EB (blue) 또는 #4F46E5 (indigo). primary 버튼만 사용 |
| B | 선명한 단일 강조 | accent #F97316 (orange) 또는 #16A34A (green) |
| C | 무채 강조 | primary 버튼 #111827, 링크·선택만 accent 최소 사용 |

역추출: "튄다/심심하다/눈에 안 띈다". 브랜드 색이 이미 있으면 이 축은 묻지 않고 그 색을 A로 고정한다.

## 축 5 — 타이포 성격

| 시안 | 값 | 수치 |
|---|---|---|
| A ★ | 균일 산세리프 | Pretendard(iOS SF·Android Roboto 폴백). h1 24/600, h2 18/600, body 15/400. 대비 낮음 |
| B | 강한 대비 | h1 32/700, h2 20/600, body 15/400, caption 12/400 |
| C | 세리프 혼합 | 제목만 세리프(Noto Serif KR), 본문 산세리프 |

역추출: "차분하다/눈에 띈다/고급스럽다"는 표현이 나오면 어떤 요소(제목 크기? 세리프?)에 반응한 것인지 번호로 확인.

## 프로젝트 추가 축 (0~2개)

PRD 도메인을 보고 필요할 때만. 예:

| 도메인 | 추가 축 | 시안 |
|---|---|---|
| 이미지·영상 도구 | 캔버스 배경 톤 | 흰색 / 중간 회색 #808080 / 체커보드 |
| 이미지·영상 도구 | 썸네일 밀도·비율 | 정사각 4열 / 16:9 3열 / 원본 비율 masonry |
| 데이터·관리 툴 | 내비 구조 | 하단 탭바 / 상단 세그먼트 탭 / 홈 허브 + 스택 |
| 콘텐츠·커뮤니티 | 카드 이미지 비중 | 이미지 큼 / 텍스트 위주 / 반반 |

## 축 간 충돌 처리

- 축 2 compact + 축 3 round(pill)는 잘 어울리지 않는다. 사용자가 둘 다 고르면 규칙 미리보기에서 함께 보여주고 "이 조합이 맞나요"를 국소 질문으로 확인한다.
- 축 1 다크 + 축 3 shadow는 shadow 대신 border 밝기 차이로 대체한다. 시안에도 그렇게 그린다.
