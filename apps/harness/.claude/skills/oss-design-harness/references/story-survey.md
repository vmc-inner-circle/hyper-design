# 고치기 — 일 설문 탭 (허브 첫 탭)

캡처만 있으면 하네스는 픽셀을 보고, 사용자는 “개선”만 말한다. 이 탭이 그 간극을 메운다. **취향·스타일 라벨은 묻지 않는다.** 도메인 스토리(누가 / 무슨 일 / 어떤 순서 / 어디까지만 바꿀지)와, 웹이면 **이미 있는 메뉴·페이지 목록**을 초보 말로 맞춘다.

처음부터 루트의 구조 설문(`structure-survey.md`)과 섞지 않는다. 없는 화면을 새로 기획하지 않는다. 표의 행은 가져온 화면의 메뉴·앵커·같은 사이트 경로에서 **하네스가 뽑은 것**만.

## 흐름

1. `[0']` 섭취가 끝난 뒤 `probe-renderer`에 `KIND=story OUT=design/probes/story.html`로 위임한다. 템플릿 `templates/story-survey.html`의 `SURVEY` 블록만 채운다.
2. hub.json 첫 탭 `{"file":"story.html","title":"이 화면의 일","prefix":"story-","stage":"3a' 일 설문"}`.
3. 사용자가 "다 봤어" → `read_db` (`feedback/story-map`, `feedback/story-1`) → brief.md §1(남은 행) + §5 + 역추출 표.
4. 그 답이 `[3b]` A/B/C/D를 그리는 입력이다. **시안은 대표 화면 1장**으로 결을 고른다. **Figma 산출은 표에 남은 행 전부**에 그 결을 적용한다. 설문이 0건이면 추천값 + 가정 로그.

## 페이지 구성

두 단위. 창 1장(팝업·웰컴)이고 메뉴가 없으면 `sections: []` — 구성 표는 숨기고 질문만.

| 단위 | 내용 | "추천대로" 의미 |
|---|---|---|
| 1 구성 | 표: 화면 / 무슨 화면인지 / 어떻게 들어가는지 / 가장 중요한 버튼. 행마다 "이번엔 빼요" | 표의 화면 전부에 다음 탭에서 고른 결을 적용 |
| 2 일 | 질문 4개, 라디오, 추천이 미리 선택. 아래에 **선택지에 없는 말** 칸(필수는 아님) | 네 질문 모두 추천값. 칸에 쓴 원문은 그대로 둠 |

## 질문 (항상 4개, 첫 칸이 추천)

| id | 묻는 것 | 초보 문장 | 선택지 뼈대 (프로젝트 카피로 채움) | brief 반영 |
|---|---|---|---|---|
| who | 배우 | 이 화면을 누가 보나요? | 처음 연 사람 / 이미 쓰는 사람 / 잘 모르겠음 | 표면 사용자 |
| job | 일 하나 | 이 화면에서 해야 하는 일 하나는? | 화면의 primary 후보 2~3개 | §1 primary 액션 |
| leftover | 순서·남는 것 | 지금 화면에서 남는 것 / 빠지는 것은? | 장식으로 보이는 구역 / 빠진 일 / 없는 것 같아요 | 영역 라벨 우선순위 |
| range | 범위 | 어디까지 바꿀까요? | 보이는 것만 (자리·메뉴 유지) / 하는 일 자체를 바꿔도 됨 | preserve vs rebuild 신호. **말로 고르지 않고 추천만.** D 추천 여부의 입력 |

`range=visual` → `[3b]` 추천은 B. `range=job` → 추천은 D.

라벨형(“모던/미니멀/고급”) 금지. “왜 디자인이 나쁜지”를 **필수로 적게 하지 않는다.** 선택지에 없는 의도(예: 가격은 두고 다운로드만 키우기)는 아래 칸에 적어도 된다. 비워 두면 선택지만으로 진행한다. 사이트맵을 빈 칸에 적게 하지 않는다.

이 탭이 **의도 인터뷰의 끝**이다. 고치기 프로세스의 끝은 아니다. 다음은 시안 A/B/C/D → 규칙 델타 → 표에 남은 화면 Figma.

## 저장

```
feedback/story-map {unit:"story", n:0, label:"메뉴·구성",
                    marks:[<이번엔 빼는 id>], markNames:[],
                    text:"추천대로"|자유, updatedAt}
feedback/story-1   {unit:"story", n:1, answers:{who,job,leftover,range},
                    text:"추천대로"|"직접 선택"|자유원문, updatedAt}
```

`story-map.marks`에 있는 행은 brief §1에서 빼고, `[5]`에도 안 그린다.

## 렌더러가 채우는 것

`templates/story-survey.html`의 `const SURVEY`.

- `screen` 이름·한 줄 목적.
- `sections[]` — 헤더 메뉴, 같은 페이지 앵커, 같은 호스트 경로. 창 1장이면 비우거나 그 창 1행. `id`는 영문 slug.
- `questions[]` — 4개. `options[0]`이 추천. `why`는 "○○가 달라집니다" (페이지가 "이걸 정하면"을 붙임).
