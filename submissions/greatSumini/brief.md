# 브리프 — 가족여행 계획 앱 "함께가요"

## 한 줄 요약
자녀는 **"작업 중" 공간**에서 후보를 마음껏 적고 고치고, 부모는 **확정된 것 + "정하는 중" 표시**만 큰 글씨로 본다. 바뀐 점은 자동으로 흩어져 가지 않고 **자녀가 모아서 한 번에 "소식"으로 보낸다.** 부모는 캐묻는 대신 **"궁금해요" 한 번 누르기**로 신호를 보낸다.

## 역할
| 역할 | 누구 | 하는 일 | 화면 차이 |
|---|---|---|---|
| 계획하는 사람 (planner) | 딸 김지은 | 일정 작성·수정, 확정/후보 표시, 할 일 나누기, 소식 보내기 | 후보까지 모두 보임, 순서 바꾸기·편집, "보낼 소식" 모음 |
| 보는 사람 (viewer) | 아빠 김영호, 엄마 박순자 | 큰 흐름 확인, 내 준비물 체크, 궁금해요 누르기 | 확정 항목만 보임, 후보는 "정하는 중"으로 한 줄 요약, 글자 17px 이상, 편집 없음 |
| 함께 가는 가족 (shared) | 아들 김민수, 며느리 이하나 | 내 할 일 확인·체크 | "내 준비" 화면 공유 |

## PRD 커버리지
- F1 일정 작성·수정 → plan-day(순서 손잡이, 항목 탭해 수정), item-edit
- F2 확정 여부 → plan-day(확정/후보 배지, "확정하기"), parent-day(확정만 표시)
- F3 역할별 다르게 → invite-family(역할 지정), parent-home/parent-day(확정만·큰 글씨·편집 없음) vs plan-day(전부)
- F4 할 일·준비물 공유 → tasks, task-add, my-checklist
- F5 변경 전달·과한 알림 방지 → send-updates(모아서 한 번, 후보 자동 제외), update-digest(한 장 요약)
- US1 후보도 편히 적고 고침·오해 걱정 → item-edit(기본 "후보"로 저장), send-updates(후보는 부모 소식에서 빠짐)
- US2 매번 묻지 않고 큰 흐름 → parent-home(5일 한 줄씩), parent-day("정하는 중"+궁금해요 한 번 누르기)
- US3 무엇을 준비·언제 어디 헷갈리지 않게 → my-checklist(모이는 곳·시간 맨 위, 내 것만)
- S1 두세 달 전부터 여러 번 바뀜 → send-updates(바뀐 점을 모아 둠)
- S2 4~6명, 손주 → invite-family(6명, 손주는 초대 없이 이름만), tasks(사람별)
- S3 3박4일~7박8일 → planner-home/parent-home 날짜 목록이 날 수만큼 한 줄씩
- S4 예약 끝난 항목 vs 계속 바뀌는 현지 일정 → 확정/후보 배지, 항공·숙소는 확정
- S5 부모는 여러 단계 조작 답답 → join-invite(버튼 1개), parent-home(한 번 누르기로 완료), viewer 17px
- S6 자잘한 할 일 → tasks·task-add
- C1 최소 두 세대 → 역할 2종 + 공유 화면

## 가정 로그
- 부모는 링크로 들어오고 가입 없음(join-invite 버튼 1개). 계정 만들기 화면 생략.
- 항목 종류(이동/숙박/활동)는 plan-day의 "항목 추가" 바텀시트에서 고르므로 item-edit에서 다시 묻지 않음.
- 새 항목은 항상 "후보"로 저장, 확정은 plan-day 목록에서 "확정하기". → 입력 2개로 줄임.
- 알림 규칙: 부모에게는 자녀가 "보내기"를 누를 때만 1번. 후보 변경은 소식에서 자동 제외. 
- 함께 계획하는 형제(민수)도 planner 화면을 쓸 수 있으나 시안은 지은 기준.
- 모이는 곳·시간은 지은이 plan-day의 12/10 첫 항목에서 입력한 값(입력 화면은 item-edit와 같아 별도 생략).
- 알림 설정 화면 생략(규칙이 고정이라 고를 것이 없음).
