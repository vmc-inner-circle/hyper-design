# 예쁨 규칙 (K13 · 2026-10-08)

> 사용자(10-08): "예쁘다는 의미는 심미적 안정성, 배치의 균형, 아이콘 및 글자 색깔 및 크기 등 — 웹디자인 문서·책에서 찾아 rule 로."
> 근거 원문·확인 등급·검사 스펙 = 저장소 밖 조사 문서(web-design-rules.md, 40규칙·출처 목록). 여기는 **그리는 사람이 지킬 숫자**만.
> **개성은 이 규칙 위에서 낸다.** 규칙은 바닥(안정감·균형)이고, 은유·시그니처 디테일·글꼴 짝·색 온도로 다르게 만든다. 규칙을 지키려고 개성을 지우지 않는다.
> 검사: `python scripts/lint.py design/v/<k>/app.html` (variants.py 가 자동으로 부름). '자동(실패)' 규칙을 어기면 자가 교정 대상, '자동(주의)' 는 시간이 남으면.

## 그리기 전에 CSS 변수로 먼저 정한다 (style.css 맨 위, 이 값만 쓴다)

```css
.app{
  /* 간격 — 4의 배수 단계(R1·R2). 묶음 안 < 묶음 사이 1.5배 이상(R3) */
  --s1:4px; --s2:8px; --s3:12px; --s4:16px; --s5:24px; --s6:32px; --s7:48px; --s8:64px;
  /* 글자 — 한 단계표(비율 1.2~1.25, R9·R10). 본문 16~17px(R8), 12px 미만 금지 */
  --f-xs:12px; --f-sm:14px; --f-md:16px; --f-lg:20px; --f-xl:24px; --f-2xl:32px; --f-3xl:40px;
  --w-reg:400; --w-mid:600; --w-bold:800;          /* 굵기 2~3종(R11) */
  --lh-body:1.6; --lh-head:1.25;                   /* 한글 본문 1.5~1.7, 제목 1.15~1.35(R12) */
  /* 색 — 글자 3단계 + 강조 1~2(R14·R19). 순검정 금지(R21). 대비 본문 4.5:1(R17) */
  /* 모양 — 모서리 2~3종(R25), 그림자 2~3단계(R24), 버튼 높이 2종(R27) */
  --r-sm:8px; --r-lg:16px; --r-pill:999px;
  --sh-1:0 1px 2px rgb(0 0 0/.06),0 1px 3px rgb(0 0 0/.08); --sh-2:0 4px 12px rgb(0 0 0/.10);
  --btn-h:48px; --btn-h-sm:40px;                   /* 폰 누르는 곳 44px 이상(R28) — 작은 버튼은 padding 으로 영역 확보 */
  --icon:20px; --icon-sm:16px; --icon-lg:24px;     /* 아이콘 크기 3종(R32) */
}
```
(이름·값은 벌마다 바꿔도 된다 — 단 **단계 수와 비율 규칙**은 지킨다. 큰 제목은 화면 하나의 주인공일 때만 --f-3xl 이상.)

## AI 가 흔히 하는 실패 (조사 문서 F1~F25 요약 — 그리기 전에 한 번 읽는다)
간격이 제각각(10·14·18·22px) · 모든 곳 같은 gap(묶음이 안 보임) · 카드 안 왼쪽 시작점이 몇 px 씩 어긋남 · PC 본문이 화면 끝까지 퍼짐 · 히어로·카드 설명·빈 상태를 전부 가운데 정렬 · 글자 크기 7~9종(13·14·15·16·17·18…) · 보조 글자 11~13px 연회색 · 첫 화면에 큰 숫자 카드 4개 · 한 섹션에 색 채운 버튼 2~3개 · 카드마다 다른 파스텔 배지 · 모든 카드에 같은 radius·같은 회색 그림자 · 테두리+그림자+배경색을 한 카드에 다 · 입력칸 테두리가 거의 안 보임 · 32px 이하 아이콘 버튼 · 모바일 가로 스크롤 · 하단 탭 6개 이상 · 아이콘 크기 섞임·글자와 세로 중심 어긋남 · 이모지 아이콘 · 한글 제목이 단어 중간에서 줄바꿈 · 영어 ALL-CAPS 꼬리표 · 뒤쪽 화면에서 버튼 높이·패딩이 흩어짐 · 지도 핀·스티커가 글자를 덮음.
