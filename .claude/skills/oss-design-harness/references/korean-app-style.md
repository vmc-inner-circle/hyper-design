# 한국 대중 앱 스타일 규격 (토스·카카오·당근 기준)

하네스의 모든 화면은 이 규격을 기본값으로 쓴다. 무드 시안은 **포인트 색과 밀도만** 다르고 아래 골격은 같다.

## 골격

- **바탕**: 페이지 배경은 연회색 `#F2F4F6`, 내용은 **흰 섹션 블록**(radius 16, 좌우 여백 없이 가득 또는 좌우 12px). 섹션 사이 간격 12px. 섹션 안에 또 카드를 넣지 않는다. 입력 폼·상세 화면은 흰 바탕 한 장.
- **좌우 여백 20px**, 섹션 안쪽 여백 20~24px.
- **큰 제목**: 화면 첫 제목 26px/700, 줄간격 1.35, 자간 -0.02em. 섹션 제목 20px/700. 본문 17px/400~500(부모 등 보기 전용 역할은 18px). 보조 글자 15px `#6B7684`. 캡션 13px `#8B95A1`은 대비가 낮으니 날짜·시간 같은 부가 정보에만.
- **글자색**: 제목·본문 `#191F28`, 보조 `#4E5968`/`#6B7684`. 순검정·회색 남용 금지.
- **목록 행**: 높이 64px 안팎, 구분선 없이 여백으로 나눈다. 왼쪽 40px 아이콘 원(연회색 바탕 + 선 아이콘) → 제목 17px/600 + 보조 15px → 오른쪽 값 또는 `›`.
- **주요 버튼**: 하단 고정, 좌우 20px, 높이 56px, radius 16, 17px/600 흰 글자. 화면당 1개.
- **보조 버튼**: 테두리 버튼 대신 **연회색 채움**(`#F2F4F6` 바탕, `#333D4B` 글자), 높이 44~48px, radius 12.
- **작은 버튼(행 안의 "확정하기" 등)**: 포인트 틴트 바탕 + 포인트 글자, 높이 36px 이상 + 터치 영역 44px.
- **배지·상태 표시**: 옅은 틴트 바탕 + 진한 같은 계열 글자, 13px/600, radius 6, 높이 22. 검정 배지 금지. "확정"은 포인트 틴트, "후보·정하는 중"은 회색.
- **탭바**: 흰 바탕, 위 경계는 1px `#F2F4F6`. 선택 탭은 **아이콘·글자만 `#191F28`**, 나머지 `#B0B8C1`. 선택 탭에 박스·배경·테두리 금지. 아이콘 24px, 라벨 11~12px(탭바 라벨만 예외적으로 12px 허용).
- **앱바**: 높이 56px, 흰 바탕(또는 페이지 배경과 같은 색), 뒤로 가기 아이콘 + 가운데 제목 17px/600. 홈에는 앱바 대신 큰 제목.
- **칩·세그먼트**: 알약형(radius 999), 높이 36 + 터치 영역 44. 기본 `#F2F4F6` 바탕, 선택은 `#191F28` 바탕 + 흰 글자(토스·당근 공통). 선택 표시는 전 화면에서 이 하나.
- **숫자 강조**: D-day·금액·인원 같은 핵심 숫자는 포인트 색 + 700.
- **아이콘**: 선 1.75px 둥근 끝, 24px. 일러스트·이모지 금지.
- **그림자**: 거의 쓰지 않는다. 바텀시트와 떠 있는 버튼만.

## 무드 시안 3종 (포인트 색만 다름)

- **A — 토스처럼**: 파랑 `#1B64DA`(흰 글자 대비 5.0), 틴트 `#E8F3FF`. 넉넉한 여백.
- **B — 카카오처럼**: 노랑 `#FEE500` 버튼 + **검정 글자 `#191919`**, 강조 글자는 `#191F28`, 틴트 `#FFF9C4`. 노랑은 버튼·배경에만 쓰고 글자색으로 쓰지 않는다.
- **C — 29CM·무신사처럼(모노)**: 버튼·강조 모두 `#191F28`, 유채색 없음. 틴트 대신 `#F2F4F6`. 사진 대신 큰 타이포로 힘을 준다.

## 하지 말 것

- 흰 바탕에 구분선만 계속 이어지는 화면(섹션 리듬 없음)
- 탁한 색(채도를 죽인 벽돌색·올리브색)
- 테두리 박스 버튼 남발, 선택 탭에 박스
- 작은 제목(20px 미만)으로 시작하는 홈
