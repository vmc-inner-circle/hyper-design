# 검수 · 사용자에게 보내는 말 — 턴마다

> 이 문서는 SKILL.md에서 나눈 참고 문서다. SKILL의 '읽기 순서'가 언제 여는지 정한다.

## 1. 사용자가 보게 되는 것 (계약 §3 요약 — 검수 기준)

0. **1턴 시안 고르기**(보드가 이 화면 하나뿐): 살펴본 서비스 카드 → 시안 5개(A 추천 · 이름 · 이유 · 특징 · 참고한 곳 · 메인 화면 3~6장을 좌우 캐러셀로 — 모두 같은 높이, 넘치는 내용은 화면 안 스크롤, 이름을 누르면 크게) · '이 안으로 할게요' · 안마다 적는 칸 → '시안 X(으)로 보내기'.

2턴부터는 두 탭으로 **이해**와 **의견**을 나눈다.
1. **사용 흐름** 탭(처음 열림) = **구역 보드**(디자이너 보드처럼 한 캔버스): 맨 위 '누가 쓰나요'(역할마다 이루려는 것 · 읽는 상황) → 구역 띠(가입·처음 시작 / 홈 / …) → 단계 이름표 → 화면을 순서대로 나란히(오류·완료 상태는 원래 화면 옆) → 화면 아래 검은 **정책 메모**(맨 위 이루려는 것 · 겪는 문제). 화살표는 **조건이 갈리는 곳에만**(`when`, 초록 화살표 + 조건 이름표, 누르는 버튼에 초록 테두리). 위쪽에 구역 바로가기·확대 도구. 화면을 누르면 화면 디자인으로.
1-1. **흐름 재생** 탭: 흐름 목록에서 하나를 고르면 화면에서 손가락이 버튼을 누르며 다음 화면으로 넘어가는 영상처럼 재생(타이핑·길게 누르기 포함). 재생/멈춤 · 이전/다음 · 속도. 구역 보드는 정적인 지도로 두고 움직임은 여기서.
2. **화면 디자인** 탭: 왼쪽 화면 목록(역할별, 맨 위 "전체" = 질문·남긴 의견) · 가운데 화면 한 장 · 오른쪽 의견(+ **이 화면의 규칙** · 사용 흐름에서 보기). 화면에서 **아무 요소나 눌러 고르고**(마우스를 올리면 "버튼 '…'" 이름표) 바꿔주세요/빼주세요 + 예시 칩 → 화면 위에 핀 번호. **아이콘**을 고르면 허용 Lucide 목록에서 바로 바꿔 볼 수 있다. 왼쪽 목록의 **안내 문구 모음** = 모든 화면의 안내·오류 문구(토스트)를 한곳에 — 위치·아이콘·색·글자를 눌러 고르면 모든 화면에 바로(`toggles.toast`), 문구마다 바꿔주세요(화면 오른쪽 '이 화면의 안내 문구'·화면에 뜬 문구를 눌러도 같다). 안내 문구는 기본이 화면 위쪽 · 본문 크기 글자.
3. 상단 **화면 느낌**: 분위기(시안 수만큼, 고른 시안의 분위기가 추천) · 글자 크기(추천 이유 한 줄) · 버튼 색(대표색 + 대안)을 한 창에서 — 고르면 모든 화면에 바로 적용.
4. 상단 **의견 보내기 · n개**(n = 추천과 다르게 고른 것 + 남긴 의견) → "이렇게 전달돼요" 확인 창 → 복사. "전체"에서 항목별 지우기·모두 지우기.

## 2. 검수 항목 (헤드리스 Chrome — 계약 §11)

- **1턴(시안 보드)**: 1440×900에서 살펴본 서비스 카드 / 시안 5개(그 시안의 메뉴 구조·분위기로 메인 화면 3~6장이 가로로) / '이 안으로 할게요' → 보내기 버튼이 '시안 X(으)로 보내기' / 칸에 적으면 개수 / 콘솔 에러 0.
- **2턴(초안 보드)**: (사용 흐름) 맨 위 '누가 쓰나요' / 구역 띠 수 = sections 수 / 화면 아래 정책 상자(맨 위 이루려는 것 · 겪는 문제) / 오류·완료 화면이 원래 화면 옆 / `when` 수만큼 초록 조건 이름표 · 시작 버튼에 초록 테두리 / 구역 바로가기 / 화면 클릭 → 화면 디자인(오른쪽 '이 화면의 규칙'). (화면 디자인) 화면 속 버튼이 제 모양 / 요소 하나 눌러 바꿔주세요 → 핀·'의견 보내기 (1)' / 콘솔 에러 0
- **3턴(최종)**: **실제 클릭**(chrome-devtools MCP `click` 또는 CDP 마우스 입력 — 페이지 안 스크립트 `.click()`으로 대신하지 않는다)으로: 사용 흐름(처음 열림) 구역 보드의 화면 수 = 화면 수 · 정책 상자 · 조건 화살표 / 화면을 누르면 크게 다가감 / 화면 전체 탭의 대지 수 = 화면 수(주소가 index.html에 머무는지) / 완성본 페이지에서 흐름 버튼·왼쪽 메뉴를 누르면 해당 페이지 / 콘솔 에러 0. **index.html에 다른 파일로 가는 링크를 넣지 않는다**(macOS Chrome 폴더 권한 문제로 '파일 액세스 거부됨').

## 3. 사용자에게 보내는 말 (이 형식 그대로)

**1턴 — 시안 보드**

```
시안을 브라우저에 띄웠어요. (runs/<project>/out/board.html)
비슷한 서비스 N곳을 살펴보고 화면 구성이 다른 시안 5개를 만들었어요. 마음에 드는 안 하나를 골라 주세요.
다른 안에서 가져오고 싶은 점은 그 안의 칸에 적어 주세요. 다 되면 오른쪽 위 버튼으로 내용을 확인하고 복사해 여기에 붙여넣어 주세요.
고른 안으로 전체 화면과 사용 흐름을 만들어 드릴게요.
```

**2턴 — 초안**

```
시안 X로 만든 초안을 띄웠어요. (runs/<project>/out/board.html)
'사용 흐름'에서 구역마다 화면이 쓰는 순서대로 놓여 있고, 화면 아래 검은 상자에 그 화면의 규칙을 적었어요. 초록 화살표는 조건에 따라 길이 갈리는 곳이에요.
고치고 싶은 화면을 누르면 '화면 디자인'에서 의견을 남길 수 있어요(규칙이 틀렸으면 화면 메모에). 화면 느낌은 위쪽에서 바꿔 볼 수 있어요. 다 되면 "의견 보내기"로 복사해 붙여넣어 주세요.
(화면 N개 · 구역 S개 · 조건 화살표 K개 · 웹|모바일)
```

**3턴 — 최종본 · 제출**(묻지 않는다)

```
최종본을 띄우고 제출했어요. (runs/<project>/out/index.html · submissions/<github_id>/)
'사용 흐름'에서 구역별 화면과 규칙을, '흐름 재생'에서 실제로 쓰는 모습을, 화면을 열면 버튼이 동작하는 완성본을 볼 수 있어요.
더 고칠 게 있으면 고칠 점이나 '의견 보내기' 글을 붙여넣어 주세요. 반영해서 다시 제출할게요.
```
