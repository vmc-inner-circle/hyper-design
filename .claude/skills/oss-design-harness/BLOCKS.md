# 화면 JSON 형식 (요약) — 화면 내용 에이전트가 읽는다 (`app.py --engine-css` 가 `design/app/BLOCKS.md` 로 복사한다)
화면 = `{"id","title","role","icon","features":["F1"],"navLabel"?,"layout"?,"blocks":[...],"side":[...]}` — layout: stack(기본)|wide|center|split|canvas
- side = PC 에서 오른쪽 보조 열(폰에서는 본문 아래로 내려감). PC 에서 적극 쓴다(미리보기·요약·다음 할 일·읽음 현황 등).
- 링크는 항목의 "to":"화면id".
- 블록 t: header{title,sub,right,back,to} · hero{img|icon,title,text} · stats{items:[{label,value,tone}]} · banner{text,tone,icon} · section{title,right} · list{title,items:[{title,sub,right,badge,tone,state(done|todo|alert|draft),icon,img,who,to}]} · checklist{title,items:[{title,sub,checked,who}]} · timeline{title,items:[{time,title,sub,badge,state(fixed|draft),who,to}]} · cards{cols,items:[{title,sub,img,icon,badge,meta,to}]} · grid{cols,items:[{label,value,icon,tone,to}]} · table{cols,rows} · kanban{cols:[{title,items}]} · buttons{items:[{label,icon,primary,to}]} · chips{items,active} · segment{items,active} · avatars{items:[{name,sub,done}]} · progress{value(0~1),label} · calendar{month,start,days,marks{"12":"done|part|miss|accent"},note} · form{fields:[{label,value,hint,kind(text|select|toggle|date)}],submit,to} · steps{items,active} · sheet{title,blocks} · empty{icon,title,body,cta,to} · text{text,size,tone} · quote{text,who} · html{html}(이 서비스만의 조각) · **형태 블록**: carousel{title,items:[{title,sub,img,badge,to}]} · map{pins:[{x,y,label,tone}],route,numbered,height} · bignum{value,label,sub} · poster{img,kicker,title,text,cta,to} · gallery{items:["gen:…"]} · chat{items:[{who,text,me}]} · tabs{items,active} · cols{cols:[[블록],[블록]]} · art{height,items:[{s:도형,c:a1~a4|ink|#hex,x,y,w(%),rot,o}],title,text} 도형으로 그린 그림
- tone: ok | warn | info | muted | alert 등 / state: 확정=fixed(또는 done), 후보=draft (점선 + 배지 '후보' — 색만으로 구분하지 않는다)
- timeline 항목은 time(문자열)을 꼭 넣는다(정해지지 않았으면 "미정").
- 사진: "img":"photo:<구체적 영어 키워드>:<숫자>". 사람 얼굴은 "gen:woman:1" 같은 그림 또는 이니셜. 이모지 금지, 아이콘은 Lucide 이름.
- 같은 사실(시간·장소·개수·이름)은 `design/brief.md` '내용 데이터'의 값 그대로 쓴다. 거기 없는 사실을 새로 만들지 않는다.
