# 한글 작성 규칙

화면의 모든 글(제목·메뉴·버튼·안내·알림·빈 상태)에 적용한다. 근거: `local/refs/korean-ux-writing.md`(토스 8원칙, 국립국어원 맞춤법·번역투, KRDS).
판단 기준 하나: **한국 사람이 말로 했을 때 자연스러운가.**

## 1. 핵심 규칙

1. **해요체로 통일.** 하십시오체·반말 섞지 않음. 오류 문구도 해요체.
   저장되었습니다 → 저장했어요 / 실패함 → 저장하지 못했어요
2. **능동형.** '~되었어요'(피동)보다 주어가 하는 말.
   일정이 등록되었습니다 → 일정을 추가했어요
3. **짧게. 뜻 없는 말을 지운다.** 고객님께서 현재 보유 중이신 일정을 확인해 보세요 → 일정을 확인해 보세요
4. **사용자 입장의 말.** 시스템·개발 용어 대신 사용자가 하는 일로.
   데이터 동기화 실패 → 다른 기기와 맞추지 못했어요 / 동의합니다 → 다 확인했어요
5. **은유·만든 말은 화면 이름·탭·메뉴·버튼에 쓰지 않는다.** 은유는 일러스트·소개 카피 같은 겉모습에만. 라벨은 2절 사전의 말을 쓴다.
   작업대 → 일정 짜기 / 안내장 보내기 → 가족에게 보내기 / 우체통 → 알림
6. **버튼은 동사로 끝나는 짧은 말**(1~4글자, 길어도 '~하기'). 무엇이 일어나는지 보이게. '예/아니요'·'확인' 하나만 쓰지 않음.
   예 / 아니요 → 삭제 / 취소 , 진행 → 결제하기 , 확인 → 일정 저장
   한 화면 안에서 '저장'·'저장하기' 중 하나로 통일. 두 버튼일 때 보조 버튼은 '취소'·'닫기'·'다음에'.
7. **질문은 '~할까요?'.** 삭제하시겠습니까? → 일정을 삭제할까요?
8. **명령·강요·겁주기 금지.** ~하기 바랍니다 / 반드시 ~할 것 → ~해 주세요. 권유하고 선택권을 남긴다.
9. **오류 문구 = 무슨 일 + 어떻게.** 사용자를 탓하지 않고 다음 행동을 준다. '오류 코드', '실패' 같은 말로 끝내지 않음.
   잘못된 입력입니다 → 날짜를 다시 골라 주세요 / 네트워크 오류 → 인터넷 연결이 끊겼어요. 연결되면 다시 시도해 주세요
10. **빈 상태 = 지금 상황 + 할 수 있는 일(버튼).** 데이터가 없습니다 → 아직 일정이 없어요 + [일정 추가]
11. **존댓말 대상은 사용자와 가족.** 사용자를 '고객님/유저'로 부르지 않고 대개 생략. 가족·초대받은 사람 이름 뒤 '님'. 앱이 스스로를 높이지 않음(저희가 해 드려요 X → 해 드려요).
12. **숫자·날짜 표기.** 숫자는 아라비아 숫자, 단위와 붙임(3개, 2명, 10분). 날짜는 '10월 12일 (월)', 숫자만 쓸 땐 '2026. 10. 12.'(마지막 마침표 포함). 시각은 '오후 3:00' 또는 '오후 3시'. 기간은 물결표 '10월 12일~14일'. 가까운 날은 '오늘·내일·어제'. 금액은 '12,000원'.
13. **번역투·어려운 한자어 금지.** 3절 표로 바꾼다. ~을 통해 → ~로, 해당 → 이, 진행하다 → 하다.
14. **영어 섞지 않기.** 한국 앱에서 굳은 외래어(앱·로그인·링크·메시지·사진)만 허용. 표기: 메시지·콘텐츠·애플리케이션(메세지·컨텐츠 X).
15. **명사형으로 끝맺지 않는 문장.** 안내문은 문장으로. 저장 완료 → 저장했어요. (탭·제목·버튼·상태 배지는 명사 허용)

## 2. 앱 표준 용어 사전 (라벨은 여기서 고른다)

- **탭·메뉴**: 홈, 일정, 캘린더, 할 일, 알림, 검색, 메시지, 사진, 지도, 가족, 기록, 내 정보, 설정, 더보기, 고객센터, 공지사항
- **화면 제목**: 일정 추가, 일정 수정, 일정 상세, 여행 계획, 할 일 목록, 장소 검색, 가족 초대, 공유 설정, 알림 설정, 프로필 수정, 로그인, 회원가입, 이용약관, 앱 정보
- **버튼**: 저장, 확인, 취소, 닫기, 다음, 이전, 완료, 추가, 수정, 삭제, 검색, 필터, 정렬, 공유, 초대, 보내기, 복사, 선택, 다시 시도, 새로고침, 더보기, 접기, 시작하기, 로그인, 로그아웃, 가입하기, 나중에, 다음에, 건너뛰기, 알림 받기
- **상태 표시**: 진행 중, 예정, 완료, 지난 일정, 오늘, 새 글, 읽음, 안 읽음, 저장됨, 불러오는 중…, 보내는 중…, 연결 끊김, 초대 보냄, 대기 중
- **알림·토스트**: 저장했어요, 삭제했어요, 링크를 복사했어요, 초대를 보냈어요, ○○님이 일정을 추가했어요, 내일 오전 9시에 출발해요, 저장하지 못했어요. 다시 시도해 주세요
- **빈 상태**: 아직 일정이 없어요, 검색 결과가 없어요, 새 알림이 없어요, 할 일을 모두 끝냈어요, 함께하는 가족이 없어요 — 가족을 초대해 보세요
- **도메인(여행·가족)**: 여행, 장소, 숙소, 교통, 준비물, 체크리스트, 예산, 메모, 구성원, 보호자, 출발, 도착

## 3. 피해야 할 말 → 대신 쓸 말

| 피할 말 | 쓸 말 | 피할 말 | 쓸 말 |
|---|---|---|---|
| 작업대 | 일정 짜기, 계획 | 안내장 보내기 | 가족에게 보내기, 공유하기 |
| 안내판 | 공지, 알림 | 수첩 | 메모, 기록 |
| 우체통 | 알림, 메시지 | 관제탑 | 한눈에 보기, 홈 |
| 보물상자 | 저장한 항목 | 여행 가방(메뉴명) | 준비물 |
| 나침반(메뉴명) | 길찾기, 추천 | 발자국 | 기록, 방문한 곳 |
| ~을 통해 | ~로, ~에서 | ~에 의해 | ~이(가), ~로 |
| ~로부터 | ~에게서, ~에서 | ~에 대한 | ~의, ~를 (빼도 됨) |
| ~을 가지고 있다 | ~이 있다 | ~하는 것이 가능합니다 | ~할 수 있어요 |
| 제공합니다 | 드려요, 볼 수 있어요 | 진행하시겠습니까? | ~할까요? |
| 진행하다 | 하다 (결제 진행 → 결제) | 완료되었습니다 | ~했어요 |
| ~되어지다 | ~되다, ~하다 | ~하시기 바랍니다 | ~해 주세요 |
| 해당 (해당 일정) | 이, 그 (이 일정) | 기재하다 | 적다, 입력하다 |
| 익일 | 다음 날 | 금일 | 오늘 |
| 상기 | 위 | 하기 | 아래 |
| 수정 요망 | 고쳐 주세요 | 미입력 | 입력하지 않았어요 |
| 불가 | 할 수 없어요 | 요청 실패 | ~하지 못했어요 |
| 유효하지 않은 | 맞지 않는, 잘못된 | 상이하다 | 다르다 |
| 조회 | 보기, 찾기 | 등록 | 추가 |
| 유저, 사용자님 | (생략), 사용자 | 고객님께서 | (생략) |
| 컨펌 | 확인 | 리마인드 | 미리 알림 |
| 어사인 | 맡기기 | 셰어 | 공유 |
| 인바이트 | 초대 | 세팅 | 설정 |
| 디테일 | 자세히 | 업데이트되었습니다 | 새로 바뀌었어요 |
| 메세지 | 메시지 | 컨텐츠 | 콘텐츠 |
| 데이터가 없습니다 | 아직 ○○이 없어요 | 로딩중 | 불러오는 중… |
| 오류가 발생하였습니다 | 문제가 생겼어요 | 성공적으로 | (빼기) |
| 보다 나은 | 더 나은 | 다양한 | (빼거나 구체적으로) |

## 4. 자동 검사 목록

검사 대상은 HTML의 보이는 글자(태그·스크립트 제외). 결과는 경고로 내고 사람이 판단한다.

### (a) 번역투·딱딱한 표현 정규식 (Python `re`)

```python
STYLE_PATTERNS = [
    (r"[을를]\s?통(해|하여)", "~을 통해 → ~로"),
    (r"에\s?의(해|하여|한)", "~에 의해 → 능동형"),
    (r"(으)?로부터", "~로부터 → ~에게서/~에서"),
    (r"에\s?대(한|해|하여)", "~에 대한 → ~의/~를"),
    (r"[을를]\s?가지고\s?있", "~을 가지고 있다 → ~이 있다"),
    (r"제공(합니다|됩니다|해\s?드립니다)", "제공합니다 → 드려요"),
    (r"(하|되)?시겠습니까", "하시겠습니까 → 할까요?"),
    (r"니다(?=[.!?\s]|$)|니까\?", "하십시오체 → 해요체"),
    (r"(되었|하였|되어졌)(습니다|어요)", "~되었습니다 → ~했어요"),
    (r"되어지|되어진|지어지", "이중 피동"),
    (r"진행(하|되|해)", "진행하다 → 하다"),
    (r"(하시기|하기)\s?바랍니다|할\s?것\.", "명령조 → ~해 주세요"),
    (r"(^|\s)해당\s", "해당 → 이/그"),
    (r"익일|금일|명일|상기|기재|요망|불가(?!능)|상이(하|한)", "어려운 한자어"),
    (r"것이\s?가능", "~하는 것이 가능 → ~할 수 있어요"),
    (r"성공적으로|다양한", "뜻 없는 꾸밈말"),
    (r"(완료|실패|성공|불가)\s*[.]?$", "명사형 끝맺음 → 문장(안내문만)"),
    (r"유저|컨펌|어사인|인바이트|셰어|리마인드|세팅", "영어 직역 → 우리말"),
    (r"메세지|컨텐츠|컨셉", "외래어 표기 오류"),
    (r"(어요|에요|해요).*니다|니다.*(어요|에요|해요)", "한 문단에 해요체·하십시오체 섞임"),
]
```

`니다` 와 명사형 끝맺음은 탭·버튼·배지(짧은 라벨)에는 적용하지 않는다.

SPACING_PATTERNS = [
