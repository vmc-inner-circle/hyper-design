## 2. 범위
- **커버한다**: 지인 풀(한 사람 여러 그룹·신랑 쪽/신부 쪽/양가), 모임 편성(1:1 포함), 후보 날짜·마감·회신 모으기, 확정과 공유(같은 링크가 바뀜), 둘의 달력 겹쳐 보기, 진행 상태 4단계.
- **커버하지 않는다**: 채팅(단톡방이 한다), 장소 예약·지도(지도·예약 앱이 한다), 모바일 청첩장 제작(이미 전문 서비스가 많다), 참석자 선물·정산.
- **경계(추천 결정)**: 초대받은 사람은 앱 설치 없이 링크 한 장으로 답한다. 확정 알림은 링크 페이지 갱신 + 답할 때 남긴 번호로 문자 한 통(자동, 예비부부가 따로 보내지 않음).
- **사람 나누기**: 하윤·민수는 똑같은 화면을 본다(쪽 구분은 필터일 뿐, 서로의 모임을 고치고 확정할 수 있다). 초대받은 사람은 자기 모임 링크만 본다.

## 4. 가정 로그 (하네스가 대신 정한 것)
1. **팔레트 — 당근(#ff6600) 기본**: 도메인(생활·동네 약속)과 성격(따뜻함)에 가장 가깝다. 버튼 글자는 토큰이 흰 글자가 가능한 짙은 톤으로 맞춘다. 대안: 마이리얼트립(신뢰·일정 앱 느낌), 에어비앤비(따뜻함·설렘). 캔버스 색 점으로 바꿀 수 있다.
2. **공유 = 링크 한 장**: 메신저가 하는 일(대화·공지)은 하지 않는다. 후보를 보낼 때 링크를 한 번 복사하면, 확정 뒤 같은 링크가 확정 안내로 바뀐다 — 다시 보낼 일이 없다.
3. **초대받은 사람은 앱 설치 없음**: 이름·번호만 확인하고 답한다. 같은 번호로 다른 커플에게 답한 기록이 있으면 "이번 시즌 내 약속"으로 한 번에 보여준다(US2).
4. **마감 지나면 기다리지 않는다**: 마감이 지나면 자동으로 "정하는 중"으로 넘어가고, 답 없는 사람은 빼고 정하거나 따로 1:1로 잡는다.
5. **탭 3개**: 모임 · 달력 · 지인. 둘이 같은 화면을 보고, 쪽 구분은 필터.
6. **"한 사람 여러 그룹"은 그룹 칩 여러 개 + 모임 편성 시 "다른 모임에도 있어요" 표시**로 푼다. 어느 모임에 넣을지는 사람이 정하지만, 이미 청첩장을 준(다녀온) 사람은 목록에서 아래로 내려간다.
