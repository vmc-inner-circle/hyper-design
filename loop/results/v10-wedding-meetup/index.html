전체 화면 한눈에 보기

화면을 누르면 크게 보고 직접 눌러볼 수 있어요 · 파란 화살표는 갈래
색

단톡방 수십 개 대신 모임마다 링크 한 장 — 답을 모으고, 확정되면 같은 링크가 바뀐다

하윤과 민수는 각자 지인 풀을 관리하지만 같은 모임 목록·같은 달력을 본다. 초대받은 사람은 앱 없이 링크로 답하고, 다른 커플에게 한 답까지 한 번에 본다. 마감이 지나면 기다리지 않고 답한 사람 기준으로 정한다.

공유는 부산물

후보를 보낼 때 복사한 링크가 확정 뒤 그대로 확정 안내가 된다 — 다시 공지할 일이 없다.

겹침은 계산해서 보여준다

후보를 고를 때와 확정할 때 둘의 다른 모임, 양가 모임과 겹치는지 '겹침' 배지로.

한 사람 여러 무리

그룹은 칩 여러 개, 모임을 짤 때 '다른 모임에도 있어요'로 중복을 막는다.

시작 · 결혼식 날짜와 짝
결혼식 날짜를 넣고 짝을 부르면 둘이 같은 화면을 쓴다
  • 결혼식 날짜는 필수 — D-day와 '급한 모임' 기준(2주 전)이 여기서 정해진다
  • 짝은 링크로 들어온다. 들어오기 전에도 혼자 시작할 수 있다
  • 내 쪽(신부/신랑)을 먼저 고르면 이후 추가하는 지인이 기본으로 그 쪽에 들어간다
상태시작 · 짝 초대 링크 복사됨
링크 복사 완료 — 민수에게 보내기만 하면 된다
  • 민수가 들어오면 홈에 민수 아바타가 붙는다
모임 · D-72
지금 내 손이 필요한 모임이 맨 위, 그다음 진행 상태 순
  • 순서: 정하는 중(할 일 있음) → 회신 받는 중 → 확정 → 다녀옴(접힘)
  • 확정 모임 날짜가 지나면 자동으로 '다녀옴'
  • 결혼식 14일 전부터 새 모임은 '급한 모임'으로 후보 1개·마감 1일 허용
지인 · 95명
쪽·그룹별로 지인을 보고, 아직 모임에 없는 사람을 찾는다
  • 한 사람이 여러 그룹에 속할 수 있다 — 행에 그룹을 모두 적는다
  • 아직 어느 모임에도 없는 사람이 위, 다녀온 사람은 아래
  • 연락처 불러오기는 권한 거부 시 직접 추가 행만 남긴다
상태지인 · 처음
아직 지인이 없을 때 — 연락처 불러오기와 직접 추가
  • 연락처 권한을 거부하면 '직접 추가'만 남는다
  • 불러온 뒤 쪽·그룹은 한꺼번에 지정
지인 고치기 · 오세린
이름·연락처·그룹(여러 개)·쪽을 고친다
  • 그룹은 여러 개 고를 수 있다 — 칩 선택은 브랜드 색
  • '1:1로 따로 만나기'를 켜면 모임 편성 때 다른 사람과 묶지 않도록 알려준다
  • 연락처는 010으로 시작하는 11자리. 지우기는 맨 아래
상태지인 고치기 · 연락처 오류
연락처 칸만 오류로 바뀐다
  • 010으로 시작하는 11자리가 아니면 저장 불가
모임 만들기 · 누구와
쪽과 인원 방식을 먼저 고르고, 사람을 고른다
  • 쪽(하윤/민수/양가 함께) → 여럿/1:1 순서로 먼저 고른다
  • 이미 다른 모임에 들어간 사람은 행에 '○○ 모임에도 있어요'
  • '1:1로 따로 만나기'로 표시된 사람은 여럿 모임에서 흐리게
모임 만들기 · 언제
후보 날짜 여러 개와 회신 마감을 정하고 링크를 만든다
  • 후보는 1~5개, 날짜마다 점심/저녁
  • 둘 중 누군가의 확정 모임과 같은 시간대면 후보 옆에 '겹침'
  • 마감은 첫 후보 날짜보다 앞서야 한다
상태모임 만들기 · 마감 오류
마감 칸만 오류로 바뀐다
  • 마감(10/18)이 첫 후보(10/10)보다 늦으면 링크를 만들 수 없다
상태모임 만들기 · 링크 복사됨
링크 복사 완료 — 단톡방에 붙여넣으면 끝
  • 이 링크 하나가 회신·확정 안내를 모두 맡는다
국문과 동기 모임 · 회신 받는 중
후보마다 누가 되는지, 누가 아직 답이 없는지
  • 후보마다 가능 인원 수와 이름
  • 마감(10/8) 전이라도 전원 답하면 '정하는 중'으로
  • 답 없는 사람은 이름만 보인다 — 재촉은 단톡방에서(링크 다시 복사)
서비스개발팀 모임 · 날짜 정하기
마감이 지났으니 기다리지 않고 날짜를 고른다
  • 가능 인원이 많은 후보가 위. 추천이어도 확정 전엔 회색
  • 둘의 다른 모임과 겹치는 후보엔 '겹침'과 그 모임 이름
  • 답 없는 사람(서도현)은 빼고 정하거나 1:1로 따로 잡기
서비스개발팀 모임 · 확정
확정 — 보낸 링크가 이미 확정 안내로 바뀌었다
  • 확정 순간 같은 링크가 확정 안내로 바뀐다 — 다시 보낼 필요 없음
  • 답할 때 번호를 남긴 사람에게 문자 한 통 자동 발송
  • 날짜 바꾸기는 여기서 — 바꾸면 링크에 새 날짜가 뜬다
달력 · 10월
하윤·민수 모임을 한 달력에 겹쳐 보고 겹치는 날을 찾는다
  • 확정 모임은 모두, 후보는 확정 모임과 같은 날일 때만 보인다
  • 겹침 = 같은 날 같은 시간대에 둘 중 한 명이 두 곳 / 양가 모임과 같은 시간대
  • 날짜를 누르면 그날 모임 목록
초대 링크 · 정지은
앱 없이 링크에서 되는 날을 고르고 보낸다
  • 후보마다 가능/안 돼요, 맨 아래 '다 안 돼요'
  • 같은 번호로 다른 커플에게 한 답이 있으면 '이번 시즌 내 약속'으로 보여준다
  • 마감 전까지 몇 번이든 고칠 수 있다
초대 링크 · 보낸 뒤
보냈다는 확인과, 확정되면 이 링크가 바뀐다는 안내
  • 보낸 답은 마감(10/8) 전까지 고치기 가능
  • 확정되면 이 링크와 문자로 알려준다
초대 링크 · 확정 후
같은 링크가 확정 안내로 바뀐 모습
  • 확정 날짜·시간·장소
  • 내 달력에 넣기(휴대폰 캘린더로 내보내기)
  • 이번 시즌 내 약속에 이 모임이 확정으로 들어간다
