전체 화면 한눈에 보기

화면을 누르면 크게 보고 직접 눌러볼 수 있어요 · 파란 화살표는 갈래
색

단톡방 수십 개 대신, 겹침이 보이는 링크 하나로 청첩장 날을 잡는다

지은과 민수는 같은 지인 풀과 같은 모임 목록을 본다. 후보를 고르는 순간, 확정하는 순간, 주말을 훑는 순간마다 '같은 사람이 같은 때 두 곳'인 겹침이 같은 자리에 뜬다. 초대받은 사람은 설치 없이 링크로 답하고, 다른 커플 모임과의 겹침도 그 자리에서 본다.

상태가 할 일을 알려 준다

마감이 지나면 '정할 차례'로 홈 맨 위에 올라온다. 알림을 하나 더 만들지 않는다.

확정 = 공유

단톡방에 붙였던 같은 링크에 확정 날짜가 뜬다. 다시 알릴 일이 없다.

어디 넣지? 를 고르는 자리에서

두 무리에 걸친 사람은 '대학 동기 모임에 있어요'가 붙어, 묶는 순간에 판단한다.

정한 것 · 뺀 것

두 사람이 따로 모은 지인 수십 명을 모임으로 묶어, 서로 겹치지 않는 날짜로 확정한다

  • 뺌앱 안 알림·채팅·자동 재촉이미 단톡방이 있다 — 방이 하나 더 생기면 PRD의 문제를 키운다
  • 뺌무리 자동 추천누구를 함께 볼지는 사람만 안다
  • 뺌장소 정하기·예약지도·예약 앱이 한다
  • 가볍게시간 단위 응답 → 점심·저녁 두 가지 '때'로답하는 사람의 일을 줄여 회신을 빠르게
  • 뺌마감 지나면 자동 확정답 없는 사람이 상사일 수도 있다
  • 뺌청첩장 전달 체크리스트새 체크 일을 만들지 않는다

    지은 대학 동기 · 답 기다림
    누가 어느 날 되는지, 누가 아직인지
    • 답 없는 사람에게는 '링크 다시 복사' — 재촉은 단톡방에서
    • 마감 뒤 늦게 온 답도 받아서 보여 준다
    • 겹치는 후보는 회신 수와 상관없이 '겹침' 표시

    겹침을 보고 날짜 하나를 확정

    • 확정하면 같은 링크에 확정 날짜가 뜬다 — 따로 알리지 않아도 된다
    • 시간·장소는 확정할 때 한 줄로(예약은 지도 앱에서)
