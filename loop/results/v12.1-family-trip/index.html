전체 화면 한눈에 보기

화면을 누르면 크게 보고 직접 눌러볼 수 있어요 · 파란 화살표는 갈래
색

후보는 짜는 사람 화면에만 두고, 확정을 누르면 그대로 가족에게 공유돼요

자녀는 미완성 후보를 마음껏 적고 고치고, 부모는 확정된 큰 흐름만 큰 글자로 봅니다. 바뀐 건 '바뀜' 표시와 하루 한 번 묶음 알림으로만 전하고, 부모는 말 대신 '이날 궁금해요'를 한 번 눌러 물어볼 수 있어요.

확정이 곧 공유

따로 '공유하기'가 없어요. 확정으로 저장하는 순간 가족 화면에 나타나고, 후보는 '정하는 중' 한 줄로 접혀요.

말 대신 궁금해요

부모는 날짜마다 한 번 '궁금해요'를 눌러요. 짜는 사람의 정할 것 맨 위로 올라가고, 그날이 확정되면 저녁 묶음 알림이 답이 돼요.

알림은 하루 한 번

확정 항목이 바뀐 날에만 저녁 8시 묶음 알림. 후보 변경은 조용히. 출발 7일 전부터 모이는 곳·비행기 시간만 바로.

정한 것 · 뺀 것

짜는 사람은 미완성을 마음 놓고 고치고, 부모는 묻지 않아도 확정된 큰 흐름을 안다 — '확정'을 누르는 것이 곧 공유다.

  • 뺌가족 단체 채팅이미 카톡 단톡방이 한다
  • 뺌경비 정산이번 갈등과 무관, 송금 앱이 한다
  • 가볍게변경 이력 전체 비교(전/후 diff) → 바뀐 것 목록에 '18:30 → 19:00' 한 줄만부모에게 필요한 건 지금 값 하나
  • 뺌후보 투표부모에게 새 할 일·결정 부담을 얹는다. 궁금해요 신호로 충분
  • 뺌예약 앱 연동·길찾기예약·지도 앱이 한다
  • 뺌묶음 알림을 2차로 미루기(PM 제안)PRD F5의 '알린다'를 지키는 최소 형태가 하루 한 번 묶음이라 유지

  • 지난 일정은 흐리게

    바뀐 것
    무엇이 바뀌었는지 지금 값 한 줄로, 알림 받는 방식과 함께
    • 확정 항목의 변경만 쌓인다 — 후보 변경은 남지 않음
    • 알림은 하루 한 번 저녁 8시 묶음, 바뀐 게 있는 날만
    • 지난 변경도 여기서 다시 볼 수 있다(배지는 3일)
    내가 챙길 것
    엄마 몫 준비물 3개만, 하나씩 체크
    • 내 몫만 보인다 — 가족 전체는 짜는 사람 화면에
    • 체크는 본인과 짜는 사람 모두 가능
    • 출발 전날 저녁 묶음 알림에 남은 것 포함
    홈 · 일정 같이 짜기 켜짐
    같은 홈에 '정할 것'이 더 붙는다 — 궁금해요가 맨 위
    • 정할 것 = 후보가 남은 시간대 4곳 + 비어 있는 날 1곳
    • 궁금해요가 붙은 날이 맨 위
    • 맡을 사람 없는 할 일도 여기 올라온다
    날짜 · 3일째 고치기
    후보를 편하게 적고 끌어서 순서를 바꾼다
    • 후보는 시간대마다 여러 개, 확정은 시간대당 하나
    • 후보를 적고 고쳐도 가족에게 표시·알림 없음
    • 끌기 손잡이로 순서 바꾸기
    일정 고치기
    확정으로 저장하는 순간 가족 화면에 나타난다
    • '확정'으로 저장하면 가족 화면에 반영 + 그날 저녁 묶음 알림
    • 시간이 없으면 확정 불가('후보'로는 저장 가능)
    • 지우기는 후보만 — 확정은 후보로 돌린 뒤
