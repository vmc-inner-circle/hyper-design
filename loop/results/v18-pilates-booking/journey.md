# 여정 — 동네 필라테스·요가 예약 앱 (수강생용)

## 사람 카드

PRD 3장의 페르소나 A·B·C를 그대로 가져온다.

### A. 김지현 — 퇴근길에 예약하는 직장인 (핵심 사람)
- 누구: 32세 한국 여성 직장인. 망원동 집 근처 '숨 필라테스 망원점'에 주 2회 평일 저녁 8시. 20회권. 야근이 잦아 당일 취소가 종종 있다.
- 처음 오는 이유: 카톡으로 "내일 8시 자리 있나요?" 묻고 30분 기다리는 게 지겨워서.
- 그때 마음: 바쁘고 조급하다. 취소하면 차감될까 늘 불안하다.
- 알고 싶은 것
  1. 이번 주 내 수업은 언제지? → `home`, `my-bookings`
  2. 지금 취소하면 횟수를 돌려받나? → `cancel`, `class`, `my-bookings`
  3. 몇 회 남았고 언제 끝나지? → `home`, `tickets`, `booking-confirm`
  4. 대기 건 수업 자리 났나? 몇 번째지? → `home`, `promotion`
- 성공한 순간: 지하철에서 1분 만에 수업 2개 예약, 오후 5시에 "차감돼요"를 미리 보고 취소 여부를 스스로 결정.
- 주로 쓰는 화면: home, schedule, class, booking-confirm, cancel, promotion, my-bookings

### B. 박서연 — 새 스튜디오를 고르는 엄마
- 누구: 38세 한국 여성, 육아 중. 성산동. 등원 후 오전 10~12시만 가능. 새 스튜디오를 찾는 중.
- 처음 오는 이유: 동네에 어떤 스튜디오가 있는지, 오전 수업이 있는지 한 번에 보고 싶어서.
- 그때 마음: 신중하다. 처음 가는 곳이라 실패하고 싶지 않다(사진·후기·강사 이력을 꼼꼼히 본다).
- 알고 싶은 것
  1. 우리 동네에 오전 수업 있는 곳은 어디고 얼마지? → `find`, `find-map`
  2. 여기 강사는 어떤 사람이고 후기는 어떤가? → `studio`, `instructor`, `reviews`
  3. 처음인데 한 번 해 볼 수 있나? → `studio`, `tickets-buy`
- 성공한 순간: 체험권을 결제하고 목요일 오전 수업을 바로 예약.
- 주로 쓰는 화면: home-new, find, find-map, studio, instructor, reviews, tickets-buy, checkout

### C. 이정호 — 다음 수업만 확인하는 재활 수강생
- 누구: 61세 한국 남성, 재활 목적. '바른몸 재활필라테스' 소도구 필라테스 주 3회, 3개월 기간권. 앱이 익숙하지 않다. 딸이 가입을 도와줬다.
- 처음 오는 이유: 딸이 "이제 전화 말고 앱으로 확인하세요"라며 깔아 줘서.
- 그때 마음: 막막하고 조심스럽다. 잘못 누를까 봐 겁난다. 글자가 작으면 포기한다.
- 알고 싶은 것
  1. 다음 수업이 언제지? → `home`, `my-bookings`
  2. 도착했는데 출석은 어떻게 하지? → `checkin`
  3. 여행 가는 동안 수강권을 멈출 수 있나? 끝나는 날은 언제로 바뀌지? → `pause`
- 성공한 순간: 스튜디오 문 앞에서 버튼 하나로 출석, 여행 전 일시정지를 혼자 신청.
- 주로 쓰는 화면: home, checkin, checkin-done, tickets, ticket-detail, pause

**핵심 사람 = 김지현.** PRD 문제 1·3·4(카톡 핑퐁·취소 규정 분쟁·대기)가 모두 지현의 하루에 모인다. 정호의 "다음 수업 먼저"는 홈 맨 위 블록으로 함께 푼다(같은 블록이 지현에게도 첫 질문의 답).

## 범위
- 커버한다: 수강생 앱의 PRD S01~S25 전부(25화면) + 결과 화면(결제 완료·예약 완료·대기 신청 완료·승급 확정 완료·취소 완료·출석 완료·일시정지 완료·리뷰 등록 완료·즐겨찾기 담음).
- 커버하지 않는다: 운영자 웹 어드민·강사 화면(PRD 범위 외), 태블릿, 1:1 개인레슨 예약(상품만 노출 — PRD), 앱 안 환불 신청(스튜디오 전화 연결 — PRD).
- 경계(추천 결정): 오류·확인·빈 상태 화면은 `/hyper-design:max`에서 더한다(1차는 기본 + 결과 화면).
- 사람 나누기: 모두 같은 수강생 화면. 둘러보기(비로그인)는 찾기·스튜디오·시간표까지 같은 화면, 예약·구매·내 예약·수강권을 누르면 `login`으로.
