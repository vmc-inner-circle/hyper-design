# 동네 필라테스·요가 예약 앱 — 기획 브리프 + MVP 기능명세서

> 작성: 서비스기획 PM / 최종 수정: 2026-10-01 / 상태: 에이전시 전달용 초안 v0.9
> "무엇을" 만들지 정리한 문서입니다. "어떻게 보일지"는 에이전시 제안을 받고 싶습니다. 미확정 사항은 7장에 모았고, 본문에도 (논의 중) 표시가 있습니다.

---

## 1. 서비스 개요

우리 동네 필라테스·요가 스튜디오를 찾고, 수업을 예약하고, 수강권을 한 곳에서 관리하는 **수강생용 모바일 앱**입니다.

동네 소규모 스튜디오(강사 1~5명)는 대부분 전화·카톡·엑셀로 예약을 받습니다. 수강생은 "몇 회 남았는지", "취소하면 차감되는지"를 매번 물어봐야 하고, 운영자는 예약 응대에 하루 1~2시간을 씁니다.

| 구분 | 설명 | MVP 범위 |
|---|---|---|
| 수강생 | 스튜디오 탐색·예약·수강권 관리 | **이번 외주 범위 (모바일 앱)** |
| 스튜디오 운영자 | 시간표·수강권 상품 등록, 회원·출석 관리 | 범위 외 — **별도 웹 어드민** (내부 개발 중) |
| 강사 | 수업 진행, 수동 출석 처리 | 범위 외 — 운영자 웹에 강사 계정으로 접속 |

**이번 외주는 수강생 앱만 해당합니다.** 앱에 보이는 시간표·정원·수강권 상품은 운영자 웹에서 입력된 데이터입니다. iOS/Android, 세로 화면 기준이며 태블릿은 범위 외입니다.

## 2. 우리가 해결하고 싶은 문제

1. **예약이 전화·카톡에 묶여 있다** — 수강생은 퇴근길에 예약하고 싶은데 스튜디오는 수업 중이라 답장이 1~2시간 늦음. "내일 7시 자리 있나요?" → (30분 후) "마감됐어요" 핑퐁. 운영자 인터뷰 8곳 중 7곳이 "카톡 응대가 가장 피곤하다".
2. **수강권 잔여 횟수가 헷갈린다** — 몇 번 썼는지 수강생도 모르고, 엑셀과 실제 출석이 안 맞기도 함. 만료 직전 몰아 쓰다 못 쓰고 만료되면 불만. 횟수권·기간권이 섞이면 더 헷갈림.
3. **취소 규정 분쟁** — "당일 취소 1회 차감"을 등록 때 한 번 듣고 잊음 → "그런 말 못 들었다". 규정을 **예약·취소 시점에 명확히** 보여줘야 함.
4. **인기 수업 대기** — 평일 저녁·주말 오전은 금방 마감. "자리 나면 연락 주세요"는 운영자가 기억해야 해서 자주 놓침. 취소 시 다음 사람에게 자동으로 기회가 가야 함.
5. (부가) **노쇼** — 예약해놓고 안 와서 대기자가 못 들어감. 운영자 요구가 강함.

## 3. 타깃 사용자와 사용 맥락

**A. 김지현 (32세, 직장인)** — 집 근처 스튜디오, 주 2회 평일 저녁 8시. 20회권. 야근 잦아 당일 취소가 종종 있어 취소 규정에 민감.
- 월요일 출근 지하철에서 이번 주 수업 2개 예약
- 오후 5시 "오늘 야근각"이면 무료 취소 가능한지 확인
- 대기 걸어둔 수업 자리 났다는 알림 받았을 때

**B. 박서연 (38세, 육아 중)** — 등원 후 오전 10~12시만 가능. 동네에서 **새 스튜디오를 찾는 중**이라 사진·후기·강사 이력을 꼼꼼히 봄. 체험 → 횟수권 구매 패턴.
- 밤 10시 아이 재우고 근처 스튜디오 둘러보기
- 등원 직후 오늘 오전 빈자리 확인, 도착해서 출석

**C. 이정호 (61세, 재활 목적)** — 소도구 필라테스 주 3회, 3개월 기간권. 앱이 익숙하지 않고 글자 크기·단계 수에 민감. 딸이 가입을 도와줌.
- 다음 수업 언제인지 확인 (거의 이것만), 도착 시 출석
- 해외여행 전 일시정지 신청

**공통**: 1회 사용 1~3분, "확인하고 닫기"가 대부분. 이동 중 한 손 사용 많음. 예상 빈도: 내 예약 확인 > 예약 > 출석 > 잔여 확인 > 스튜디오 탐색 > 취소.

## 5. 화면별 명세

> 번호는 편의상 붙였고, 에이전시 제안에 따라 합치거나 나눠도 됩니다. 표시 요소와 정책은 빠지면 안 됩니다.

### S01. 스플래시 / 첫 실행 안내
- **진입**: 앱 실행
- **표시**: 서비스 로고, (최초 1회) 소개 2~3장 — "동네 스튜디오 한 번에", "남은 횟수 바로 확인", "자리 나면 자동 알림"
- **동작**: 넘기기/건너뛰기 → 로그인
- **정책**: 로그인 유지 중이면 바로 홈. 강제 업데이트 버전이면 스토어 이동 안내.

### S02. 로그인 / 가입 방법 선택
- **진입**: S01 이후, 로그아웃 후, 로그인 필요한 기능 접근 시
- **표시**: 카카오로 시작, Apple로 시작(Android 노출 여부 확인 중), 전화번호로 시작, 약관 링크, "둘러보기"(비로그인 탐색)
- **동작**: 기존 회원 → 홈 / 신규 → S04
- **정책**: 같은 전화번호로 다른 방식 가입 이력 있으면 "이미 ○○로 가입된 번호" 안내. 둘러보기 중 예약·구매 시도 시 이 화면으로.

### S03. 전화번호 인증
- **진입**: S02 전화번호 선택, 카카오·애플 신규 가입 중(전화번호 필수)
- **표시**: 번호 입력, 인증번호 6자리, 남은 시간 3:00, 재전송
- **정책**: 유효 3분, 재전송 30초 후·하루 5회. 5회 오입력 시 10분 제한. 문자 자동 채우기 지원.

### S04. 약관 동의 + 기본 정보
- **진입**: 신규 가입
- **표시**: 전체 동의, [필수] 이용약관·개인정보·만 14세 이상, [선택] 마케팅 수신, 이름(실명), 닉네임, 성별·생년(선택)
- **동작**: 필수 체크 + 이름 입력 시 다음 → S05
- **정책**: 이름은 스튜디오 출석부용, 운영자에게만 공개. 리뷰엔 닉네임만. 닉네임 중복 허용(으로 가정).

### S05. 동네 설정
- **진입**: 가입 직후, 홈의 동네명, 마이페이지
- **표시**: 현재 위치로 설정, 동 이름 검색·결과, 최근 동네(최대 3)
- **동작**: 현재 위치 → 위치 권한 요청 → 행정동 자동 설정 / 검색 선택 → 홈
- **정책**: 권한 거부해도 검색으로 설정 가능. 동네는 1개만(집/회사 2개는 이후 검토). 권한 요청 타이밍은 논의점 1.

### S06. 홈
- **진입**: 로그인 후 기본 화면
- **표시**
  - 현재 동네명, 알림(안 읽은 개수)
  - **다음 수업**: 일시, 스튜디오, 수업명, 강사, "출석하기"(30분 전부터)
  - 내 수강권 요약: 만료 임박 순 1개의 잔여/만료일 + "외 n개"
  - 대기 중 수업 순번, 확정 필요한 승급 건
  - 오늘 빈자리 있는 수업(다니는 스튜디오), 동네 추천 스튜디오
- **동작**: 다음 수업 → S11 / 수강권 → S20 / 추천 → S08
- **정책**: 예약 없음 → "예정된 수업이 없어요" + 시간표 유도. 수강권 없음 → 구매 유도. 다니는 스튜디오 없는 신규는 찾기 영역 우선. 페르소나 C 때문에 "다음 수업"이 가장 먼저 보였으면 함.

### S07. 스튜디오 찾기 (지도 / 목록)
- **진입**: 주요 메뉴, 홈 추천
- **표시**
  - 지도/목록 전환, 스튜디오명 검색
  - 필터: 종목(기구 필라테스/매트/요가), 거리(500m/1km/3km), 시간대(오전/오후/저녁/주말), 체험 가능
  - 정렬: 거리순, 리뷰 많은 순, 별점순
  - 지도: 위치 표시, 선택 시 요약(이름, 거리, 별점, 사진, 오늘 빈자리 수)
  - 목록: 대표 사진, 이름, 종목, 거리, 별점(리뷰 수), "1회 ○○원~"
- **동작**: 지도 이동 후 "이 지역에서 다시 찾기", 선택 → S08
- **정책**: 권한 없으면 설정 동네 중심. 결과 0개 → "3km로 넓혀볼까요?". 입점 스튜디오만 노출. 기본 보기는 논의점 2.

### S08. 스튜디오 상세
- **진입**: 찾기, 홈, 내 예약의 스튜디오명, 알림
- **표시**
  - 사진(최대 10장, 전체 보기), 이름, 종목, 별점·리뷰 수, 주소, 거리
  - 소개, 운영시간, 휴무일
  - **강사**: 사진, 이름, 한 줄 소개 → S09
  - **시설**: 주차, 샤워실, 탈의실, 락커, 운동복 대여, 기구 종류(리포머/캐딜락/체어 등), 정원 규모
  - 수강권 상품(가격, 횟수/기간, 유효기간), 취소 규정 요약
  - 리뷰 요약 + 최근 3개 → S22
  - 지도·길찾기(외부 지도 앱), 전화하기, 즐겨찾기
  - **시간표 보기/예약하기** (항상 접근 가능)
- **정책**: 일시 휴업이면 안내 + 예약 진입 막음. 사진 없는 스튜디오 대비 기본 이미지. 취소 규정은 MVP에선 플랫폼 공통(R1~R2) — 논의점 5.

### S09. 강사 상세
- **진입**: 스튜디오 상세, 수업 상세의 강사명
- **표시**: 사진, 이름, 경력, 자격증, 전문 분야(재활, 산전산후 등), 이번 주 수업, 강사 리뷰
- **정책**: 여러 스튜디오 출강 강사도 MVP에선 스튜디오별 별도 프로필.

### S10. 수업 시간표 (주간)
- **진입**: 스튜디오 상세, 주요 메뉴의 "예약"(다니는 스튜디오로 바로), 홈
- **표시**
  - 스튜디오명(여러 곳 다니면 전환), 주간 날짜(이번 주·다음 주, 이전/다음 이동)
  - 선택일 수업: 시작~종료, 수업명, 강사, 종목/난이도, 잔여석 "3/6", 상태
  - 상태: 예약 가능 / 마감 임박(1~2석) / 마감(대기 n명) / 대기 마감 / 내가 예약함 / 대기 중(순번) / 지난 수업 / 휴강
  - 필터: 강사, 종목, 시간대
- **동작**: 수업 선택 → S11
- **정책**: 14일 이후 수업은 "○월 ○일 오픈" 표시(R14). 휴무일은 "휴무"(R12). 하루 15개 넘는 스튜디오도 있어 많아도 보기 편해야 함.

### S11. 수업 상세
- **진입**: 시간표, 홈, 내 예약, 알림, 강사 상세
- **표시**
  - 수업명, 일시, 소요시간, 스튜디오, 강사(→S09), 종목, 난이도(입문~고급), 소개
  - 정원·잔여석, 대기 인원, 준비물/유의사항("양말 필수" 등)
  - **취소 규정**: "○월 ○일 ○○:○○까지 무료 취소, 이후 1회 차감" — 실제 날짜로 계산
  - 사용할 수강권(자동 선택, 변경 가능)
  - 상태별 행동: 예약 / 대기 신청 / 예약 취소 / 대기 취소 / 출석 / 리뷰 쓰기
- **동작**: 예약 → S14 / 대기 → S15 / 수강권 없음 → "이 스튜디오 수강권이 없어요" + S12
- **정책**: 예약한 수업이면 예약 정보(예약 시각, 사용 수강권) 함께. 시간 겹치는 예약 있으면 불가(R10). 휴강 시 사유 표시(R13).

### S12. 수강권 선택
- **진입**: 스튜디오 상세, 수업 상세(수강권 없음), 수강권 관리
- **표시**: 스튜디오명, **횟수권**(체험 1회/10회/20회/30회)·**기간권**(1·3·6개월, 주 n회 제한 가능), 상품별 가격·회당 가격·유효기간(10회 2개월 등)·일시정지 가능 여부, 환불 규정 요약
- **동작**: 상품 선택 → S13
- **정책**: 체험권은 해당 스튜디오 첫 구매자만. 1:1 개인레슨은 상품만 노출하고 예약은 스튜디오와 직접 조율(논의 필요) — 앱 예약은 그룹 수업만. 같은 스튜디오 수강권 여러 개 보유 가능.

### S13. 결제 / 결제 완료
- **진입**: S12 상품 선택
- **표시**: 상품 정보, 시작일(기간권만: 오늘/첫 수업일/직접 선택, 30일 이내), 쿠폰 입력, 결제 수단(카드, 카카오페이, 네이버페이, 토스페이), 최종 금액, 환불 규정 동의(필수)
- **동작**: 성공 → 완료(구매 수강권 요약, "바로 예약하기", "홈으로"). 수업 상세에서 왔으면 그 수업 예약으로 바로 이어주기.
- **정책**: 실패·이탈·중복 결제는 R11. 영수증은 마이페이지 결제 내역.

### S14. 예약 확인 / 예약 완료
- **진입**: 수업 상세 → 예약
- **표시**: 수업 요약, 사용 수강권, "10회 → 9회 (예약 시 차감, 무료 취소 시 복원)", 취소 규정(매번 표시, "확인했습니다" 체크는 첫 예약만), 예약 확정. 완료 후: 캘린더 추가, 내 예약 보기, 위치 보기.
- **정책**: 확정 순간 마감됐으면 "방금 마감됐어요. 대기할까요?". 예약 제한 중(R4)이면 불가 + 해제일. 차감 시점은 **예약 시**(출석 시 아님 — 잔여 초과 예약 방지).

### S15. 대기 신청
- **진입**: 마감 수업 상세 → 대기 신청
- **표시**: 현재 대기 인원, 내 예상 순번, 규칙 안내(순서대로 알림, 2시간 내 확정, 시작 3시간 전 자동 해제), 사용할 수강권
- **정책**: 신청 시 차감 없음(확정 시 차감). 최대 5명(R5). 겹치는 시간대 대기는 가능, 확정 때 체크(R10).

### S16. 대기 승급 확정
- **진입**: 승급 푸시, 알림함, 내 예약의 대기 항목
- **표시**: "자리가 났어요!", 수업 정보, 확정 마감 카운트다운 "1시간 42분 남음", 확정 / 이번엔 포기
- **동작**: 확정 → 예약 완료 / 포기 → 다음 순번으로
- **정책**: R6. 확정 시점에 잔여 0·만료면 확정 불가 → 다음 순번.

### S17. 예약 취소
- **진입**: 수업 상세, 내 예약
- **표시**: 수업 정보, **무료 취소 여부** — "지금 취소하면 횟수를 돌려받아요" vs "무료 취소 기간(○일 ○시)이 지나 1회 차감돼요", 취소 사유(선택), 취소 확정
- **동작**: 완료 → 변경된 잔여 안내. 대기자 승급은 자동(수강생에겐 안 보임).
- **정책**: 수업 시작 후 취소 불가(노쇼). 대기 취소는 언제든 무료. 기간권 늦은 취소는 임시로 페널티 없음 — 논의점 4.

### S18. 내 예약 목록
- **진입**: 주요 메뉴, 홈
- **표시**
  - 예정: 일시, 스튜디오, 수업명, 강사, D-day, 무료 취소 마감까지 남은 시간
  - 대기 중: 수업 정보, 현재 순번, 확정 필요 건 강조
  - 지난 수업: 출석 / 노쇼 / 무료 취소 / 차감 취소 / 휴강, 리뷰 작성 여부
- **동작**: 선택 → S11, 리뷰 미작성 → S21
- **정책**: 지난 수업은 최근 3개월 + 더 보기. 예정 0개면 시간표 유도.

### S19. 출석 체크
- **진입**: 홈 "출석하기", 수업 상세, 수업 30분 전 알림
- **표시**: **QR 스캔**(데스크 비치 QR) 또는 **도착 확인**(스튜디오 반경 100m), 완료 안내(수업명, 시간)
- **동작**: QR → 카메라 권한 → 스캔 성공 시 출석 / 도착 확인 → 위치 확인 후 출석
- **정책**: 출석 가능 시간 R15. 방식은 스튜디오별 설정(QR만/도착만/둘 다). 다른 스튜디오 QR이면 에러. 위치 실패 시 "QR로 출석하거나 강사님께 말씀해주세요"(강사 수동 출석 가능). 노쇼 판정은 R3.

### S20. 수강권 관리
- **진입**: 주요 메뉴(또는 마이페이지 안 — 논의점 6), 홈 요약
- **표시**
  - 스튜디오별 수강권: 상품명, **잔여/전체**, 시작~만료일, 남은 일수, 상태(사용 중/일시정지/만료/소진/환불)
  - 만료 7일 이내 강조
  - 상세: 사용 내역(날짜, 수업, 차감/복원 사유), 일시정지 이력, 남은 정지 횟수·일수
  - 수강권 구매, 일시정지 신청 → S21
- **정책**: 만료·소진은 "지난 수강권"으로 따로. 환불은 앱 신청 X, 스튜디오 전화 연결. 잔여는 **"잔여 7회 (예약 2회 포함)"**처럼 예약분을 같이 표시.

### S21. 수강권 일시정지
- **진입**: 수강권 상세 → 일시정지
- **표시**: 남은 정지 횟수(최대 2회)·일수(총 30일), 시작일/종료일, 변경 만료일 미리보기 "12.10 → 12.24", 정지 기간 내 예약 목록 + "자동 무료 취소됩니다"
- **동작**: 신청 즉시 적용(운영자 승인 없음). 정지 중 "조기 해제" 가능.
- **정책**: R9. 시작일은 오늘 이후만.

### S22. 리뷰 작성 / 리뷰 목록
- **진입**: 수업 종료 후 알림, 지난 수업, 스튜디오 상세(출석 이력 있을 때)
- **표시(작성)**: 수업 정보, 별점 1~5, 좋았던 점 복수 선택(친절해요/자세 교정 꼼꼼/시설 깨끗/강도 적당/주차 편함…), 텍스트(10~500자), 사진 최대 3장(**허용 미정**, 논의점 3)
- **표시(목록)**: 평균 별점, 분포, 상위 키워드, 리뷰(닉네임, 날짜, 수업/강사, 별점, 내용), 정렬(최신/높은순/낮은순), 강사 필터, 운영자 답글, 신고
- **정책**: 출석한 수업만, 수업 후 14일 이내, 1회당 1개. 수정·삭제 가능. 욕설 필터. 답글 작성은 운영자 웹.

### S23. 알림함
- **진입**: 홈 알림, 푸시 선택
- **표시**: 종류, 내용, 시간, 읽음 여부. 종류는 아래.
  - 예약 확정 / 취소 완료 / 휴강
  - 리마인드(전날 21시 + 2시간 전), 무료 취소 마감 3시간 전
  - 대기 승급(확정 필요) / 대기 자동 해제
  - 수강권 만료 임박(7일·1일 전) / 잔여 1회
  - 노쇼 처리, 예약 제한
  - 리뷰 요청(종료 1시간 후), 결제 완료/실패
- **동작**: 선택 → 관련 화면
- **정책**: 90일 보관. 확정 마감 지난 승급 알림은 "만료됨".

### S24. 마이페이지
- **진입**: 주요 메뉴
- **표시**: 프로필(닉네임, 이름, 전화번호)·수정, 이번 달 출석 횟수, 수강권 요약, 결제 내역·영수증, 내가 쓴 리뷰, 즐겨찾는 스튜디오, **노쇼 현황**(최근 30일 n회, 제한 중이면 해제일), 동네 설정, 설정, 고객센터(FAQ, 카카오톡 채널)
- **정책**: 노쇼 현황 노출은 의견 갈림. 분쟁 예방 차원에서 일단 표시.

### S25. 설정
- **진입**: 마이페이지
- **표시**: 알림 설정(전체/예약·대기/리마인드/마케팅), 위치 권한 상태 + 시스템 설정 이동, 연결된 로그인 계정, 약관·라이선스·버전, 로그아웃, 회원 탈퇴
- **정책**: 대기 승급 알림은 끌 수 없게(또는 끄면 대기 불가) — 개발팀 확인. 탈퇴 시 잔여 수강권 있으면 "소멸됩니다, 환불은 스튜디오에 먼저 문의" 경고 + 재확인, 예정 예약은 자동 취소 안내.

> 공통: 네트워크 오류, 서버 점검, 권한 거부(위치·카메라·알림), 빈 상태 화면도 필요합니다. 문구가 위에 없으면 에이전시 제안.

## 6. 데이터 규칙·정책

> 화면 명세와 중복돼도 이쪽이 기준입니다.

- **R1. 무료 취소**: 수업 시작 **24시간 전까지** 취소 시 횟수 복원.
- **R2. 늦은 취소**: 시작 24시간 이내~시작 전 취소 시 **1회 차감**. 기간권은 임시로 페널티 없음(논의점 4).
- **R3. 노쇼**: 예약 후 미출석 시 **1회 차감** + 노쇼 1회 누적. 판정은 수업 종료 후 운영자 출석부 확정 기준, 미확정이면 종료 6시간 후 자동 확정.
- **R4. 예약 제한**: 최근 30일 노쇼 **3회 누적 시 7일간 신규 예약·대기 불가**(전 스튜디오 공통). 기존 예약은 유지. 해제 후 카운트 초기화.
- **R5. 대기 정원**: 정원 초과 시 대기 가능, 수업당 **최대 5명**.
- **R6. 대기 승급**: 자리가 나면 1순번에 승급 알림. **2시간 내 미확정 시 자동 포기 → 다음 순번**. 시작 3시간 전까지 승급 못 받은 대기는 자동 해제. 시작 2시간 미만에 승급되면 확정 마감은 시작 30분 전.
- **R7. 잔여 0**: 가용 잔여(예약분 제외)가 **0이면 예약·승급 확정 불가**. 대기 신청은 가능, 확정 시 재확인.
- **R8. 만료**: **만료일 지난 수강권 사용 불가**. 수업 날짜가 만료일 이후면 그 수강권으로 예약 불가. 만료 시 잔여 소멸.
- **R9. 일시정지**: 수강권당 **최대 2회, 합산 최대 30일**, 1회 최소 3일. 정지 기간만큼 만료일 연장. 정지 기간 내 예약은 자동 무료 취소, 정지 중 예약 불가. 조기 해제 시 실사용 일수만 차감. 체험권·1개월 미만 상품은 불가.
- **R10. 중복 예약 금지**: 1분이라도 **시간이 겹치는 수업은 스튜디오가 달라도 중복 예약 불가**. 대기는 겹쳐도 신청 가능, 승급 확정 시 겹치면 불가.
- **R11. 결제 실패**: 실패 시 수강권 미발급, 사유(한도 초과, 잔액 부족, 사용자 취소 등) 안내 + 재시도/수단 변경. 승인 후 발급 실패 시 자동 결제 취소 + 고객센터 안내. 진행 중 이탈 건은 10분 후 자동 취소. 같은 상품 1분 내 재결제 시 확인.
- **R12. 휴무일**: 정기·임시 휴무일에는 수업이 없고 시간표에 "휴무" 표시. 기간권은 휴무일에도 기간이 흐름. 단 스튜디오 사정으로 3일 이상 연속 임시 휴무 시 기간권 연장(운영자 웹 처리).
- **R13. 휴강**: 휴강 시 예약자 자동 취소 + 횟수 복원 + 알림, 대기자 자동 해제.
- **R14. 예약 오픈/마감**: 수업 시작 14일 전부터 시작 시각까지 예약 가능. 시작 후 취소 불가.
- **R15. 출석 시간**: 시작 30분 전~시작 후 15분까지 앱 출석. 이후는 강사 수동 출석만.
- **R16. 수강권 범위**: 구매한 스튜디오에서만 사용. 여러 개면 **만료일 빠른 것부터** 자동 선택.

## 7. 논의점 (아직 안 정한 것)

1. **위치 권한 타이밍** — (A) 가입 직후 동네 설정 / (B) 지도 처음 열 때 / (C) 도착 확인 출석 때만. B·C가 허용률은 높을 듯하나, 동네를 수동 검색하게 되면 첫 경험이 번거로움. 에이전시 의견 원함.
2. **찾기 기본 보기: 지도 vs 목록** — 동네 기반이라 지도가 직관적 vs 사진·리뷰 비교하는 B에겐 목록. 마지막 본 방식을 기억할지도 같이.
3. **리뷰 사진 허용** — 신뢰도↑ vs 탈의실·타 회원 얼굴 노출, 검수 부담. 운영자 8곳 중 3곳 반대. MVP 제외 후 1차 업데이트도 검토.
