단톡방 수십 개 대신 링크 하나 — 답도, 확정도, 겹침도 한곳에

예비부부는 지인을 무리로 묶어 모임을 만들고 날짜 후보 링크를 단톡방에 붙인다. 지인은 설치 없이 답하고, 확정되면 같은 링크가 확정 화면으로 바뀐다. 둘의 모임은 한 달력에 모여 같은 날 두 곳이면 '겹침'으로 보인다.

확정 = 공유

확정하면 이미 보낸 링크가 확정 화면으로 바뀐다. 공지를 다시 돌리지 않는다.

상태는 저절로 넘어간다

마감이 지나면 확정 앞둠, 날짜가 지나면 다녀옴. 누를 버튼이 없다.

여러 무리에 걸친 사람

사람을 고를 때 '다른 모임에도 있어요'로 알려 주고 막지는 않는다.

정한 것 · 뺀 것

흩어진 지인 수십 명을 모임으로 묶고 날짜를 맞추는 일을, 예비부부 두 사람이 단톡방 수십 개 대신 한 곳에서 보고 겹치지 않게 확정한다

  • 뺌앱 안 채팅카톡 단톡방이 이미 한다 — 방이 하나 더 늘 뿐
  • 뺌장소 추천·예약지도·예약 앱이 한다
  • 가볍게마감 리마인더 푸시 → 마감이 지나면 홈 맨 위 '확정할 모임'으로 올라온다알림을 늘리지 않고도 기다림이 끝나는 순간을 알 수 있다
  • 나중에자동 모임 편성 추천무리 데이터가 쌓이기 전엔 추천 품질이 낮다
  • 뺌밥값 정산송금 앱이 한다
  • 가볍게겹침 판정 → 같은 사람이 같은 날 두 모임이면 '겹침'PM 반박 — 시간대 계산 없이도 실제 충돌(10/24)은 잡히고 설명이 쉽다

          모임 만들기 · 누구와
          무리에서 사람을 골라 한 모임으로 묶는다
          • 여럿 / 1:1을 먼저 고른다 — 1:1이면 한 명만 고를 수 있다
          • 다른 모임에 이미 있는 사람은 행에 '○○ 모임에도 있어요' — 막지는 않는다
          • 한 명 이상 고르기 전까지 버튼이 꺼져 있다
          모임 만들기 · 날짜 후보와 마감
          날짜 후보 여러 개와 회신 마감을 정해 링크를 만든다
          • 이미 확정된 모임이 있는 날은 후보 옆에 누구 모임인지 표시
          • 마감은 하루·3일·5일·일주일 — 결혼식 2주 전부터는 하루가 기본
          • 링크 하나로 구성원 전원이 답한다(앱 설치 없음)

              모임 · 확정 앞둠
              답 없는 사람을 빼고 날짜를 정한다, 다 안 되면 새 후보
              • 답 없는 사람은 빼고 정한다 — 그 사람은 지인 목록에서 '아직 모임 없음'
              • 전부 안 되는 날뿐이면 새 후보 보내기(같은 링크 유지)
              • 확정하면 이미 보낸 링크가 확정 화면으로 바뀐다 — 따로 보낼 것 없음
              모임 · 확정
              확정 날짜·장소와 구성원이 무엇을 보고 있는지
              • 구성원은 같은 링크에서 날짜·장소를 본다
              • 날짜를 다시 정하면 링크 맨 위에 '날짜가 바뀌었어요' 한 줄이 3일 동안 보인다
              • 날짜가 지나면 자동으로 '다녀옴'
