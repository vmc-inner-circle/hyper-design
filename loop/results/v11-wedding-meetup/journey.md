# 여정표 — 청첩장모임 스케줄러 (가칭 "모임날")

## 여정표

| 시기 | 사람 | 할 일 | 궁금해지는 것 | 막히는 순간 → 푸는 화면 |
|---|---|---|---|---|
| 사용 전 (D-80) | 지은(예비신부) | 앱을 열고 결혼식 날짜를 넣고 민수를 부른다 | 민수도 같은 걸 보나? 민수 쪽 사람도 여기 넣나? | 민수가 안 들어옴 → `start--done`(링크 복사, 카톡으로 전달) |
| 사용 전 | 지은·민수 | 각자 지인을 연락처에서 불러와 무리로 나눈다 | 하윤이는 동기이자 전 직장 동료인데 어디에 넣지? 팀장님은 따로 봐야 하는데? | 연락처 권한 거부 → 직접 추가 / 한 사람이 두 무리 → 둘 다 소속 가능 (`people`, `person-edit`) |

| 사용 중 | 지은 | 날짜 후보 3개와 회신 마감을 정해 단톡방에 링크를 붙인다 | 이 날 민수 쪽 모임이 이미 있나? 마감은 며칠이 적당하지? | 후보 날짜에 이미 확정된 모임 → 날짜 옆에 표시 (`gathering-dates`) |
| 사용 중 | 하윤(초대받은 지인) | 링크를 열어 날짜마다 된다/안 된다를 누른다 | 이날 다른 커플 모임이랑 겹치나? 앱 깔아야 하나? 전부 안 되면 어떡하지? | 전부 안 됨 → "다 안 돼요" 답 / 답 누락 → `respond--error` |
| 사용 중 | 하윤 | 이번 시즌 받은 모임을 한 번에 본다 | 내가 뭐라고 답했더라? 확정된 건 언제 어디지? | 여러 커플 요청이 흩어짐 → `respond-mine` |
| 사용 중 | 지은 | 회신을 모아보고 기다린다 | 누가 아직 답을 안 했지? 마감까지 며칠? | 며칠째 답 없음 → 마감 지나면 자동으로 "확정 앞둠"으로 넘어옴 (`gathering-decide`) |
| 사용 중 | 지은 | 답 없는 사람을 빼고 날짜를 확정한다 | 답 안 한 사람은 어떻게 하지? 모두 되는 날이 없으면? | 전부 안 됨 → 새 후보 보내기 / 답 없는 사람 → 다른 모임으로 옮기거나 따로 (`gathering-decide`) |
| 사용 중 | 모임 구성원 | 같은 링크를 다시 열어 확정 날짜·장소를 본다 | 결국 언제로 됐어? | 공유 누락 → 확정하면 같은 링크가 확정 화면으로 바뀜(추가 행동 없음) |

| 사용 중 (D-14) | 민수 | 급하게 1:1 모임을 잡는다 | 남은 주말 중 빈 날은? | 마감 짧게(하루) + 빈 날만 후보로 (`gathering-dates`) |

## 범위
- **커버한다**: 지인 풀(무리 여러 개 소속, 1:1 표시), 모임 편성, 날짜 후보·마감·회신 수합, 확정(같은 링크가 확정 화면으로 바뀜), 둘의 전체 일정·겹침, 진행 상태 4단계, 지인의 한눈 회신.
- **커버하지 않는다**: 채팅(카톡 단톡방이 한다), 장소 검색·예약(지도·예약 앱), 모바일 청첩장 발송, 밥값 정산, 푸시 리마인더(마감 지나면 홈 맨 위로 올라오는 것으로 대신).
- **경계(추천 결정)**: 회신은 앱 설치 없이 링크로. 마감이 지나면 자동으로 "확정 앞둠". 확정 날짜가 지나면 자동으로 "다녀옴".
- **사람 나누는 방식**: 지은·민수는 똑같은 화면을 보고 똑같이 고칠 수 있다(누구 쪽 지인인지만 표시). 지인은 링크로 들어와 자기 회신과 자기가 받은 모임만 본다.

## 가정 로그 (하네스가 대신 정한 것)
1. **색**: 기본 마이리얼트립 팔레트(파랑) — 성격 키워드 '신뢰'와 맞고, 결혼 앱에 흔한 분홍·빨강은 오류 색과 겹친다. 대안 에어비앤비(따뜻함)·컬리(차분) — 캔버스 색 점으로 교체.
2. 회신은 앱 설치 없이 링크로 받는다 — 지인에게 설치를 요구하면 답이 더 늦어진다.
3. 확정 공유는 새 행동이 아니라 **같은 링크가 확정 화면으로 바뀌는 것**으로 한다 — 단톡방에 이미 붙여둔 링크를 다시 열면 된다.
4. 마감이 지나면 알림 대신 홈 맨 위 "확정할 모임"으로 올라온다. 답 없는 사람은 빼고 정할 수 있다.
5. "겹침"은 같은 사람(지은 또는 민수)이 **같은 날** 두 모임에 있을 때 — 시간 계산 없이 쉽게 설명된다.
7. 지인은 같은 전화번호로 받은 링크들을 묶어 '내 청첩장모임'으로 본다. 다른 커플 일정은 이 앱으로 받은 것만 안다.
8. 답 없는 사람 재촉은 푸시 대신 이름이 들어간 문구 한 줄을 복사해 단톡방에 붙인다.
6. 지인은 여러 무리에 동시에 소속될 수 있고, 모임에 넣을 때 "다른 모임에도 있어요"로 알려 준다(막지 않음).
