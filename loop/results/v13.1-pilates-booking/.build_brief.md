## 원칙
1. 이해가 먼저, 예쁨은 나중. 화면마다 핵심 메시지 한 문장. 설명 문구로 이해시키는 UI는 실패다.
2. 기존 행동의 부산물로 푼다. 사용자에게 새 할 일을 얹지 않는다. 결제·길찾기·전화는 외부 앱으로 넘긴다.
3. 사람을 역할 이름으로 나누지 않는다. "게스트·읽기 전용" 같은 호칭 금지.
4. 덜어낸다. 모든 섹션은 "누구를 위해, 언제 보는가"가 있어야 한다. 같은 목적 버튼 중복 금지. 빈약한 통계·장식 금지.
5. 뻔한 게 이긴다. 회색 바탕 + 흰 블록, 큰 제목, 64px 목록 행, 56px 하단 버튼. 한 화면에 한 가지 일.
6. 하단 고정 CTA(`.cta` + body `has-cta`)는 폼·확인·결정·결과 화면에만. 홈·탭 첫 화면(home, home-new, find, find-map, my-bookings, mypage, passes)에는 두지 않는다. 문구는 확정 동사(예약하기·결제하기·확정하기·취소하기·저장) — "~보기"는 링크. 상황에 따라 생기는 할 일은 블록 안 인라인 버튼.
7. 색·글자·여백은 토큰만. 인라인 style·색 값 하드코딩 금지(.range 예외만).
8. 채워진 버튼은 흰 글자(토큰이 처리).
9. 배지는 배지 표만. 시간·순서(오늘·D-3·~까지·2번째)는 글자. 선택 상태(칩·세그먼트·체크·스위치)는 전부 브랜드 색 하나(자동).
10. 아이콘: 사물·주제 = 컬러 일러스트 `../assets/fluent/<이름>.svg`(calendar·ticket·pin·phone·clipboard·idcard·shoe·walk·weather·coffee·invite·eyes·car 등 COMPONENTS.md 목록만), 누르는 것 = 선 아이콘, 사람 = 글자 아바타 `<span class="avatar is-text">오</span>`(강사 사진이 있는 곳은 thumb 사진). 인물 일러스트(mother 등) 쓰지 말 것. 유니코드 이모지 금지. 오류 문구엔 경고 선 아이콘. 사진 자리는 실제 이미지 경로(아래).
11. 한국어 조판. 제목 짧게. 더미 데이터는 사실 표 그대로.
12. 탭바: 홈·찾기·내 예약·마이 4개. 탭 첫 화면(home, home-new, find, find-map, my-bookings, mypage)에만 `<nav class="tabbar">` + body `has-tab`. href: home.html / find.html / my-bookings.html / mypage.html. 지금 탭은 `aria-current="page"`.
13. PRD의 동사마다 조작 수단. 누르는 모든 것은 실제 `<a href="다른화면.html">`로 잇는다(자기 화면 링크 금지, 없는 파일 금지 — 화면 id 목록: splash login phone-verify signup-terms neighborhood home home-new find find-map studio instructor reviews timetable class book book-done waitlist promote pass-shop checkout checkout-done my-bookings cancel checkin review-write notifications passes pass-detail pause mypage settings). 외부 앱(길찾기·전화·카톡 채널·스토어)은 `href="tel:023341182"` 등.
14. 입력 순서: 규칙을 바꾸는 선택이 앞, 필수 입력은 실행 버튼 위.
15. 오류 상태는 같은 화면·같은 요소에서 문제 칸만 바뀐다(`field is-error` + `field-msg` 경고 아이콘). `--done`은 같은 화면 맨 위 `<p class="done">` + 눌린 뒤 모습(+되돌리기). `--confirm`은 기본 화면 위에 `<div class="dim"></div><div class="sheet">` 대화상자 — 위험한 확인(차감·소멸)은 주 버튼을 브랜드 채움으로 하지 말고 오류 색 글자 버튼(btn secondary 등, 토큰 범위에서)으로, "돌아가기"를 함께.
16. 상태 화면(<id>--<state>)은 **기본 화면 파일을 복사해 바뀐 부분만 고친다**(구조·제목·블록 동일). 기본 화면을 먼저 완성한 뒤 복사.
17. 보이는 글은 모두 한국어. 설명 카드("~를 누르면 ~돼요") 반복 금지 — 화면당 부가 설명 1개까지.
18. 세그먼트·탭이 있으면 선택된 탭의 내용만 보여 준다.
19. 같은 숫자(잔여 7회·예약 가능 5회·남은 시간)는 모든 화면에서 같게. 잔여 표기: 큰 숫자 "잔여 7회", 작게 "예약 2회 포함 · 지금 예약 가능 5회".
20. h1은 화면당 정확히 1개. 뒤로 버튼은 앱바 `appbar-btn`(href = 들어온 화면).
21. 이정호 님(61세)도 쓰는 앱 — 글자를 작게 줄이지 말 것, 탭 대상 44px 이상.
