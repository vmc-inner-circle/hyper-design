4. out/screens.json — 맡은 화면 항목(purpose·policies·branches·traits), badges 표(이 이름·색만 사용).
5. 구조 참고: $SK/foundation/examples/*.html (구조만, 내용 베끼지 말 것). 단 예시의 tokens 경로는 무시하고 반드시 `<link id="tokens" rel="stylesheet" href="../tokens.css"><link rel="stylesheet" href="../components.css"><script src="../palette.js"></script>`.

공통 규칙:
- 파일: out/screens/<id>.html, 자기 파일만 쓴다. h1 정확히 1개.
- 앱 이름: 모임장. 보는 사람은 기본 한서윤(예비신부). 날짜 표기 예: 10월 23일(금) 저녁 7시 30분.
- 탭바(3곳): 모임 → home.html, 달력 → calendar.html, 지인 → people.html. 탭바는 home, home-d14, calendar, people 에만(body has-tab). 탭 화면엔 하단 고정 CTA 금지.
- 화면 사이 링크(실제 href): 홈 날짜 정할 차례 모임 → decide.html · 답 모으는 중 대학 동기 → meeting.html · 새 모임 → meeting-new.html · meeting-new 다음 → meeting-dates.html · meeting-dates "링크 만들기" → meeting.html · 지인 행/+추가 → person-edit.html · 무리 관리·+새 무리 → groups.html · 시작 → partner-invite.html → home.html. 뒤로 버튼도 적절한 화면으로.
- 선 아이콘은 인라인 svg (viewBox 0 0 24 24, fill none, stroke currentColor, stroke-width 1.75). 경고 아이콘은 삼각형+느낌표 선 아이콘.
- 배지: 확정 is-brand · 날짜 정할 차례 is-warning · 답 모으는 중 is-info · 다녀옴 is-success · 후보 (클래스 없음). 다른 배지 이름 만들지 말 것. 겹침은 배지가 아니라 `<p class="info">`(경고 선 아이콘 + "군대 동기와 겹쳐요") 혹은 row-sub 글자.
- 상태 화면(<id>--error / --done)은 기본 화면을 복사해 문제 칸만 is-error로, 또는 맨 위 `<p class="done">…</p>` + 되돌리기/고치기.
- 설명 블록은 화면당 최대 1개, "~를 누르면" 같은 조작법 설명 금지. 사람 아바타는 글자 아바타(avatar is-text). 인물 일러스트(jieun 등)는 쓰지 않는다.
- 끝나면 만든 파일 목록만 짧게 보고.
