# 빌드 공통 지시 (모든 화면 빌더)

작업 폴더: /private/tmp/hd/run12f/work/out  (SK = /private/tmp/hd/run12f/work/.claude/skills/oss-design-harness)

반드시 먼저 읽을 것:
1. $SK/SKILL.md 의 "## 원칙" 섹션 1~19 전부 — 그대로 지킨다.
2. $SK/foundation/COMPONENTS.md 전문 — 이 클래스만 조합한다. 인라인 style·색 값(#xxx) 금지, 이모지 금지, title 속성 금지.
3. out/journey.md — 특히 "3. 시나리오 데이터 표"와 "4. 사실 표". **표에 없는 날짜·시간·숫자·상태를 지어내지 말 것.** 모든 날짜·시간·인원·상태 이름은 표 그대로.
4. out/screens.json — 내가 맡은 화면 항목(purpose·policies·branches·kind·role)과 badges 표(확정 is-brand / 바뀜 is-warning / 궁금해요 is-info / 완료 is-success / 후보 클래스 없음). 이 5개 배지 이름 외 배지 금지. 시간·순서(오늘·다음·~까지)는 배지 말고 글자.
5. 모범 답안 구조 참고: $SK/foundation/examples/*.html (구조만, 내용 베끼지 말 것. 단 예시는 href="tokens.css"지만 우리는 반드시 ../tokens.css).

파일 규칙:
- out/screens/<id>.html, 뼈대는 COMPONENTS.md 그대로: <link id="tokens" rel="stylesheet" href="../tokens.css"><link rel="stylesheet" href="../components.css"><script src="../palette.js"></script>
- 일러스트: ../assets/fluent/<이름>.svg (beach calendar car clipboard coffee eyes father hayun hotel idcard invite jieun luggage meal minsu mother phone pill pin plane shoe ticket umbrella walk weather). 사람 아바타: mother(어머니) father(아버지) jieun(지은) minsu(민수) hayun(하윤).
- 선 아이콘은 인라인 <svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="1.75" stroke-linecap="round" stroke-linejoin="round" aria-hidden="true">.
- h1 은 화면당 정확히 1개.
- 화면 사이 이동은 실제 <a href="다른화면.html">. 존재하는 화면 파일 이름만 쓴다: join home home-d3 home-trip day changes checklist home-edit day-edit item-edit item-edit--error tasks task-add family family--done (.html)
- "가족 화면"(role everyone)은 어머니 이순자 시점, body class="text-large". "짜는 사람 화면"(role editor)은 지은 시점.
- 사람을 역할 이름(보기만·게스트·읽기 전용·확인만)으로 부르지 않는다. 이름(어머니·아버지·지은·민수·하윤)으로 부른다.
- 하단 고정 CTA(div.cta + body has-cta)는 폼·확인·결정·결과 화면에만. 홈에는 절대 없음. 문구는 확정 동사.
- 설명 카드(설명 한 줄만 든 블록)는 화면당 최대 1개, "~를 누르면" 같은 조작법 설명 금지.
- 탭바 없음.
- 한국어. 완료 후 만든 파일 목록과 한 줄 요약만 돌려준다.

앱 핵심: 후보는 짜는 사람(지은·민수)에게만 보이고, 가족에게는 확정된 것 + "정하는 중 · 12월 3일까지"만 보인다. 확정 저장이 곧 공유(공유 버튼 없음). 알림 규칙은 journey.md 사실 표의 "알림 규칙" 그대로.
